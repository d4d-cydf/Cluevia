在服务器上的默认存储是SQLite. 连接到同一服务器的浏览器可以一起查看保存的案例。 在每个浏览器中存储了手动卡位置和一些屏幕状态。

## 导入单个图 [#개별-그래프-가져오기]

在首页的 **Load Graph JSON** 中选择已完成的 `.json` 文件。服务器不可用时，可明确选择浏览器本地保存这一替代方案。

| 项目 | 限制 |
| --- | --- |
| 文件大小 | 2,000,000 字节以内 |
| 方案 | `schemaVersion: "1.0"` |
| 对象、关系、事件 | 分别最多 200、500、300 项 |
| 来源、组 | 分别最多 30、12 项 |

系统先验证原始 JSON 的字段与引用。有效图沿保存流程分配新图 ID，并保存为 `origin: "imported"`。系统不会自动修复缺失字段或错误 ID。最小示例见[图数据契约](/zh/docs/reference/graph-document)。

上传原始资料是另一条路径。CSV 或文档的上传限制与已完成图 JSON 的 2MB 限制不能混为一谈。

## 两种导出格式 [#두-가지-내보내기]

| 屏幕 | 结果 | 重新进口 |
| --- | --- | --- |
| 个体图 |  `그래프ID.graph.json`  | 只要符合一般图合同和尺寸限制。 |
| 综合分析案例 |  `.case.json` 快照 | 目前没有支持 |

整合快照包含完整整合图、记录列表、证据关联与属性差异，但不包含每一区段的全部原文和完整抽取结果。完整备份应使用服务器数据目录。

## 服务器数据备份 [#서버-데이터-백업]

先关闭服务器，再复制默认的 `.cluevia/` 或由 `CLUEVIA_DATA_DIR` 指定的**完整数据目录**。SQLite 使用 WAL 时，仅复制单个 DB 文件可能遗漏最新记录。

取消任务后，已完成上传的文件及已保存的局部结果仍保留；中途断开的上传所留下的不完整文件会被清理。

## 浏览器存储替代方案 [#브라우저-저장-대안]

仅保存在浏览器中的图限于相同协议、主机和端口下访问。迁移到其他浏览器或设备时，须导出 JSON 后再导入。存储空间不足或访问受阻会导致保存失败，因此应保留原始文件。

## 删除案例 [#케이스-삭제]

从案例库删除案例会终止其正在执行的任务与对话，并移除对应结果、记录、对话和专用上传资料。其他案例共享的资料仍保留，外部备份也不会被删除。删除操作不能替代 JSON 导出或服务器备份。
