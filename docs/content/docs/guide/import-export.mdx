기본 저장소는 서버의 SQLite입니다. 같은 서버에 연결한 브라우저는 저장된 케이스를 함께 조회할 수 있습니다. 수동 카드 위치와 일부 화면 상태는 각 브라우저에 저장합니다.

## 개별 그래프 가져오기

홈의 **그래프 JSON 불러오기**에서 완성된 `.json` 파일을 선택합니다. 서버가 없어 연결할 수 없는 경우에는 화면에서 명시적으로 선택하는 브라우저 저장 대안을 제공합니다.

| 항목 | 제한 |
| --- | --- |
| 파일 크기 | 2,000,000바이트 |
| 스키마 | `schemaVersion: "1.0"` |
| 객체·관계·사건 | 최대 200·500·300개 |
| 출처·그룹 | 최대 30·12개 |

원래 JSON의 필드와 참조를 먼저 검증합니다. 유효한 그래프는 `origin: "imported"`로 저장하며, 저장 경로에서 새 그래프 ID를 부여합니다. 누락된 필드나 잘못된 ID를 자동 복구하지 않습니다. 최소 예제는 [GraphDocument 계약](/docs/reference/graph-document)에 있습니다.

원본 자료 업로드는 별도 경로입니다. 큰 CSV·문서의 업로드 한도와 완성된 그래프 JSON의 2MB 제한을 혼동하지 마세요.

## 데이터 내보내기

| 화면 | 결과 | 재가져오기 |
| --- | --- | --- |
| 개별 그래프 | `그래프ID.graph.json` | 일반 그래프 계약과 크기 제한을 만족하면 가능 |
| 통합 분석 케이스 | `.case.json` 스냅샷 | 현재 지원하지 않음 |

통합 스냅샷에는 전체 통합 그래프·기록 목록·근거 연결·속성 차이가 포함됩니다. 원문 전체와 구간별 전체 추출 결과는 포함되지 않습니다. 전체 자료 보존용 백업은 서버 데이터 디렉터리를 사용합니다.

## Report 보관과 공유

케이스의 **Report**에서 생성한 보고서는 생성 당시의 분석 질문, Why 검토 결과, 점수, 공백, 인용과 그래프를 함께 보관합니다. 이후 케이스에 자료를 추가해도 기존 보고서의 내용은 바뀌지 않습니다. 변경된 결과를 담으려면 새 보고서를 생성합니다.

| 형식 | 포함 내용 | 사용 방법 |
| --- | --- | --- |
| HTML | 보고서 본문, 정적 그래프, 공백·다음 조치, 출처와 직접 인용 | 파일을 브라우저에서 열어 읽거나 전달합니다. 외부 글꼴·이미지·스크립트를 불러오지 않습니다. |
| Markdown | 본문, 인용 각주, 전체 저장 노드·연결 목록과 공백 | 텍스트 편집기나 Markdown 뷰어에서 확인합니다. |
| PDF | HTML의 인쇄용 문서 | **Print / PDF**에서 브라우저의 PDF 저장 기능을 선택합니다. 용지는 A4입니다. |

정적 그래프는 저장된 연결만 그립니다. 붉은 공백 연결은 검토 대상 범위이며 실제 사건 관계가 아닙니다. 60개 이하의 노드는 모두 표시하고, 그보다 큰 그래프는 각 종류별로 최대 10개를 표시하며 표시·전체 개수를 함께 적습니다. 생략한 연결을 다른 연결로 대체하지 않습니다. Markdown에는 전체 저장 노드·연결이 남습니다.

보고서의 **Confidence**는 저장된 근거 지지 점수입니다. 관측으로 확인한 사건의 진실 확률을 뜻하지 않습니다. 미평가 점수는 `—`로 표시하고, 출처·인용·검토 한계를 함께 보존합니다. 보고서 파일은 읽기와 공유를 위한 결과물이며 케이스 재가져오기나 원자료 전체 백업을 대신하지 않습니다.

## 서버 데이터 백업

서버를 종료한 뒤 기본 `.cluevia/` 또는 `CLUEVIA_DATA_DIR`로 지정한 **데이터 디렉터리 전체**를 복사합니다. SQLite가 WAL을 사용하는 동안 DB 파일 하나만 복사하면 최신 기록이 누락될 수 있습니다.

업로드가 완료된 파일과 저장된 부분 결과는 작업 취소 후에도 유지합니다. 전송 자체가 중단된 파일의 미완성 데이터는 정리합니다.

## 브라우저 저장 대안

브라우저에만 저장한 그래프는 같은 프로토콜·호스트·포트의 해당 브라우저에서 사용할 수 있습니다. 다른 브라우저나 기기로 옮기려면 JSON을 내보내서 가져옵니다. 저장 공간이 부족하거나 차단되면 저장 오류가 발생하므로 원본 파일을 보관하세요.

## 케이스 삭제

보관함에서 케이스를 삭제하면 진행 중인 작업·대화를 종료하고 해당 결과·기록·대화·전용 업로드를 삭제합니다. 다른 케이스가 공유하는 자료는 유지하며 외부에 만든 백업은 삭제하지 않습니다. 삭제는 JSON 내보내기나 서버 백업을 대신하지 않습니다.
