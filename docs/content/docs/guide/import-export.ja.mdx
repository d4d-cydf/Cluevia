---
title: "保存とインポート"
description: "サーバーの保存、個々のグラフのJSON、統合ケースのスナップショットとデータディレクトリのバックアップの範囲を区別します。"
---

デフォルトのリポジトリはサーバーのSQLiteです。同じサーバーに接続したブラウザは、保存されたケースを一緒に検索できます。手動カードの位置と一部の画面状態は各ブラウザに保存されます。

## 個々のグラフをインポートする [#개별-그래프-가져오기]

ホームの**グラフJSONインポート**で完成した`.json`ファイルを選択します。サーバーがないために接続できない場合は、画面で明示的に選択するブラウザーの保存方法を提供します。

| アイテム | 制限 |
| --- | --- |
| ファイルサイズ | 2,000,000バイト |
| スキーマ | `schemaVersion: "1.0"` |
| オブジェクト・関係・事件 | 最大200・500・300個 |
| 出典・グループ | 最大30・12個 |

元の JSON 内のフィールドと参照が最初に検証されます。有効なグラフは `origin: "imported"` として保存され、新しいグラフ ID が保存パスに指定されます。欠落しているフィールドや間違った ID は自動的には修復されません。最小限の例は [GraphDocument契約](/ja/docs/reference/graph-document) にあります。

元の素材のアップロードは別々のパスです。大きなCSV・文書のアップロード制限と完成したグラフJSONの2MB制限を混同しないでください。

## 2つのエクスポート [#두-가지-내보내기]

| 画面 | 結果 | 再インポート |
| --- | --- | --- |
| 個別グラフ | `그래프ID.graph.json` | 一般グラフ契約とサイズ制限を満足すれば可能 |
| 統合分析ケース | `.case.json`スナップショット | 現在サポートされていません |

統合スナップショットには、全体の統合グラフ・記録リスト・根拠リンク・属性差が含まれます。原文全体と区間別の全体抽出結果は含まれません。完全なデータ保存のバックアップはサーバーデータディレクトリを使用します。

## サーバーデータのバックアップ [#서버-데이터-백업]

サーバーをシャットダウンしてから、デフォルトの`.cluevia/`または`CLUEVIA_DATA_DIR`で指定した**データディレクトリ全体**をコピーします。 SQLiteがWALを使用している間に1つのDBファイルのみをコピーすると、最新の履歴が見つからない可能性があります。

アップロードが完了したファイルと保存された部分的な結果は、ジョブのキャンセル後も維持されます。転送自体が中断されたファイルの未完成データはクリーンアップされます。

## ブラウザの保存の代替 [#브라우저-저장-대안]

ブラウザにのみ保存したグラフは、同じプロトコル・ホスト・ポートの該当ブラウザで使用できます。他のブラウザやデバイスに移動するには、JSONをエクスポートしてインポートします。保存容量が不足またはブロックされると保存エラーが発生するため、元のファイルを保存してください。

## ケースを削除 [#케이스-삭제]

ライブラリからケースを削除すると、進行中の作業・会話を終了し、該当結果・記録・会話・専用アップロードを削除します。他のケースが共有する資料は保持し、外部で作成したバックアップは削除しません。削除はJSONエクスポートまたはサーバーのバックアップに代わるものではありません。
