新分析在 `/analysis/:jobId` 中作为一个整合案例打开。公开示例与手动导入的图在 `/case/:graphId/overview` 中打开。原有 `/board`、`/lanes` 链接仍然有效；旧的 `/timeline` 链接转至 Overview。

## 分析进展和记录 [#분석-진행과-기록]

在首页 **Paste source text or URLs** 中每行输入一个文章地址时，系统会在设计前读取 HTML 正文。最多处理 8 个链接，并同时保存取得的正文与原地址。部分链接受阻时，继续使用已读取资料，并在结果中说明遗漏原因。全部链接读取失败时，会在调用模型前显示原因，便于重试。需要登录、仅返回拦截页或依赖脚本的正文，以及 PDF，可能需要手动添加文本。

如果数据经过正常审查，但没有足够的相关证据，则将完成的结果和判断理由保存，而不是分析错误。 实际读取，模型和验证错误单独显示。

左侧面板显示本体设计、资料准备、抽取、证据验证与存储阶段。**ACTIVITY** 汇总服务器实际报告的处理信息和耗时；处理说明解释当前步骤的作用。区段总数尚未确定时，不显示进度百分比。

首个结果产生前显示图准备界面。实际图仅来自验证并保存完成的区段，后续保存结果会自动加入。更新时保留已有图与选择；更新失败时保留旧结果，并提示重新加载。

分析记录对应原文处理区段。可通过顶部信息图标选择 **Records · N** 打开记录，区分没有提取到对象的结果与尚未处理的区段。失败或取消后恢复时，保留已完成记录并继续处理剩余部分。

## 一起处理多个案件 [#여러-케이스-함께-작업하기]

分析过程中，可通过案例库的 **New case** 或顶部 **NEW CASE** 输入另一项请求与资料。原任务仍在服务器继续执行。首页显示后台分析状态；切换案例或刷新页面不会取消分析。

默认同时运行两个案例。执行槽位已满时，新案例进入等待队列；运行与等待任务合计最多 5 个。取消一个案例不影响其他案例的执行和已保存结果。资料、问题和范围按案例分别维护。

**New case** 重置当前输入与澄清问题草稿，并打开新输入页面。通过徽标返回首页或刷新时，尚未提交的问题可以保留。已经在服务器开始的分析不会因这些操作被删除。

## 屏幕组合 [#화면-구성]

| 面积 | 显示内容 |
| --- | --- |
| 左侧栏 | 使用标题左侧的切换图标，在 **Case library ↔ Current case** 之间切换。两个面板不会并排占用空间。在案例模式下，侧栏显示分析活动，或已完成的整合案例的对话。 |
| 中央工作区 | Overview 展示直接回答问题的对象和关系；难以用图表达时，显示简短报告。**Review** 用于检查条件、判定与未完成或失败案例的证据缺口，并保留实际失败状态。 |
| 详情窗口 | 选择对象或关系后，详情窗口在图上方展开。通过 **Details**、**Summary**、**Sources** 及整合案例中的 **Records** 切换内容。点击 **×**、按 `Escape` 或点击画布空白处可关闭窗口；图的尺寸与选择状态会保留。 |
| 案例信息 | 点击顶部信息图标打开详情窗口。在 **Summary** 中核对问题、已确认目的、范围、预期结果及本体；不另设底部说明或会话脚本区域。 |

## 三种视图 [#세-가지-보기]

| 视图 | 如何阅读 |
| --- | --- |
| Overview | 仅展示直接回答问题的对象与关系。例如，查询转运船舶时，连接资料中明确记载转运关系的船舶。若不适合用图回答，则显示含结论、关键依据和限制的简短报告。 |
| Board | 追踪对象之间的关系，拖动卡片调整位置。 |
| Lanes | 按组列进行类型和连接的比较。 |

视图顺序为 **Overview → Board → Lanes**，新案例默认打开 Overview。Overview 从已存储图中选择直接答案，不另行调用模型或执行依据诊断。以转运问题为例，无关的所有权或位置关系、单纯相遇与近距离记录，以及推断、否认、撤回或不确定关系，均不作为直接答案。即使关系明确且带有来源，也只是资料中的陈述，并非自动事实核查。选择对象或关系可查看详情与来源；完整图保留在 Board / Lanes，逻辑检查与证据缺口保留在 Review。

简短报告从已有来源中选取与问题相关的结论和依据，使数量、事件细节等难以用连线表达的答案也能通过文字阅读。资料不足时，明确说明无法确认的内容，不根据单纯相遇或推测生成转运结论。分析中保留进度提示，搜索无结果时保留搜索提示。

屏幕距离不代表地理距离或关系强度。移除 Timeline 标签不会删除已保存的事件数据，也不会移除导出 JSON 中的 `events`。

使用缩放与 **Fit** 调整视图。拖动位置按案例和视图保存在当前浏览器，不会与其他浏览器同步。

**Focus** 隐藏侧栏，让当前图占满屏幕。使用 **Exit focus** 或 `Escape` 可恢复原先的界面及侧栏状态。选择状态和图布局会保留，分析也会继续。移动端优先显示图，活动与对话则在侧栏中打开。

## 搜索和大图 [#검색과-큰-그래프]

搜索覆盖对象名称、类型、说明、属性值以及关系和事件文本。匹配关系的两个端点也作为上下文保留。案例对话的原文搜索是独立功能。

在大型图表中，使用类型，连接范围和页面来选择一次显示的项目。 它将总数与目前可见的数量分开，不缩小存储数据或出口。 你可以把它缩小到选定的对象的直接或两步连接。

显示集合的精确规则与上限见[探索与缓存](/zh/docs/algorithms/exploration)。

## 验证基础和主张 [#근거와-주장-확인]

选择对象、关系或事件后，图上方详情窗口的 **Details** 显示属性和来源。打开证据记录时，可在同一窗口查看对应记录的原文区段与引文，并分页阅读已保存原文。同一对象在不同记录中的属性值不一致时，会显示差异。

`reported` / `inferred` 表示关系依据的表达方式，`claim.stance` 记录主张的肯定、否认、撤回或不确定状态；用户审查状态另行记录。任何一项都不构成自动事实验证。

## 案例对话与案例库 [#케이스-대화와-보관함]

已完成案例的对话通过检索已保存记录及相关原文作答。当前所选对象作为上下文，引文可打开对应记录核查。不能将尚未取得或未传给模型的资料视为不存在或错误。

案例对话填满侧栏的剩余高度，仅消息列表独立滚动，输入框固定在底部。临时切换至案例库再返回时，正在撰写的问题和对话状态都会保留。**Case context** 显示问题，**Activity** 展示实际分析进度记录。准备回答时，**Thinking** 显示服务器报告的进度及所引用记录数。回答所依据的原文可在可展开的 **Sources** 区域中查看。

通过徽标左侧的切换按钮打开或关闭整个侧栏。选择已有案例后，同一侧栏切换为该案例的活动与对话。点击标题左侧图标可重新打开案例库并选择其他案例。桌面端内部不再显示重复的折叠按钮；移动端面板可通过 **×**、点击外部区域或按 `Escape` 关闭。

案例库的垃圾桶按钮会删除案例。需要保留的资料应先[备份](/zh/docs/guide/import-export)。

应用标签、按钮及简短状态名使用英语；分析说明、证据判定、错误与提示使用韩语。原文和用户问题不作改写翻译。
