新しい分析は、`/analysis/:jobId`で1つの統合ケースとして開きます。公開例と手動でインポートしたグラフは`/case/:graphId/overview`で開きます。既存の`/board`・`/lanes`リンクはそのまま使用でき、以前の`/timeline`リンクはOverviewに移動します。

## 分析の進捗と記録 [#분석-진행과-기록]

ホームの **Paste source text or URLs** に記事の URL を一行ずつ入力すると、設計前に HTML 本文を読み取る。最大 8 リンクを処理し、取得本文と元 URL を一緒に保存する。一部のリンクが遮断された場合は、読めた資料で続行し、取得できなかった理由を結果に残す。すべて読み取れなければ、モデル呼び出し前に理由を表示する。ログインが必要なページ、遮断ページ、PDF、スクリプトに依存する本文などでは、利用者によるテキスト追加が必要な場合がある。

資料を正常に見直しても関連する根拠がない場合は、分析エラーの代わりに完了した結果と判断の理由を保管します。実際の読み取り・モデル・検証エラーは区別して表示します。

左側のパネルで、オントロジー設計、材料の準備、抽出、根拠の検証、および保存手順を確認します。 **ACTIVITY**には、サーバーが報告した実際の処理メッセージと時刻が蓄積され、処理ガイドには現在のステップの役割と経過時間が表示されます。全区間数が確定していない場合は、進捗率を表示しません。

最初の結果の前に、**グラフ準備画面**が表示されます。検証・保存が終わった部分から実際のグラフが表示され、その後保存された結果も自動的に反映されます。更新中は、既存のグラフと選択項目を保持します。更新に失敗した場合は、以前の結果と再読み込みガイドが表示されます。

**分析記録**は原文処理区間に対応します。上部情報アイコンで**レコード・N**を選択して**分析履歴**を開くと、オブジェクトのない結果とまだ処理していない区間を区別できます。失敗・キャンセル後に再開すると、完了した記録を維持したまま残りの区間を処理します。

## 複数のケースで作業する [#여러-케이스-함께-작업하기]

分析中に、ライブラリ内の**New case**または上部**NEW CASE**に別々の要求と資料を入力することもできます。既存の分析はサーバー上で実行され続けます。ホームでは、バックグラウンド分析の状態を確認し、ライブラリから目的のケースに戻ります。別のケースに移動または更新しても、実行中の分析はキャンセルされません。

デフォルト設定は2つのケースの同時実行です。実行席がなければ新しいケースは待機し、実行中・待機中のジョブは合わせて最大5個まで受け付けます。あるケースをキャンセルしても、他のケースの実行と保存の結果には影響しません。資料・質問・範囲はケース別に分離します。

**New case**は入力中の確認質問のドラフトを初期化し、新しい入力を開きます。ロゴを介してホームに戻るか更新すると、まだ送信されていない確認質問のドラフトを復元できます。すでにサーバーで開始された分析は、どの動作でも消去されません。

## 画面構成 [#화면-구성]

| エリア | 表示内容 |
| --- | --- |
| 左サイドバー | タイトルの左側にあるコンバージョンアイコンで**Case library↔Current case**を置き換えます。両方のパネルが並んでスペースを占有しません。ケースモードでは、分析アクティビティまたは完了した統合ケースの会話が表示されます。 |
| 中央作業画面 | **Graph**の**Overview**で質問に直接答えるターゲットとの関係のみを表示します。グラフに答えることが難しい場合は、結論から読むことができる短いレポートを表示します。完了または失敗したケースの検証条件・判定・根拠の欠落は**Review**タブで確認し、失敗状態はそのまま維持します。 |
| 詳細ウィンドウ | オブジェクト・関係を選択すると、グラフの上に詳細ウィンドウがスムーズに開きます。 **Details**、**Summary**、**Sources**、統合ケースの**Records**にコンテンツを切り替えます。 **×**、`Escape`、またはグラフの空白スペースを押して閉じ、グラフのサイズと選択を維持します。 |
| ケース情報 | 上部情報アイコンをタップして詳細ウィンドウを開きます。 **Summary**で質問、確定した分析目的・範囲・希望する結果とオントロジーを確認します。別途下段説明・セッションフッターは置きません。 |

## 3つのビュー [#세-가지-보기]

| 見る | 読む方法 |
| --- | --- |
| Overview | 質問に直接答える対象との関係だけを簡単に表示します。たとえば、積み重ねられた船が見つかった場合は、材料に積み替え関係が指定されている船舶間で接続します。グラフで表現する答えがなければ結論・核心根拠・確認限界を盛り込んだ短い報告書を表示します。 |
| Board | オブジェクト間の関係に従います。カードをドラッグして位置を調整します。 |
| Lanes | グループごとの列でタイプと接続を比較します。 |

表示順は **Overview → Board → Lanes** で、新しいケースでは Overview を最初に開く。Overview は保存済みグラフから直接の答えとなる関係を選び、別のモデル実行や根拠診断を要求しない。積み替えを問う場合、無関係な所有・位置関係、単なる遭遇・近接、推論・否認・撤回・不確実な関係は答えとして扱わない。出典付きの明示的関係も資料に記された主張であり、自動的な事実確認ではない。対象を選ぶと既存の詳細と出典を開ける。全グラフは Board / Lanes、論理検査と根拠の欠落は Review に残る。

短いレポートは既存のデータから 質問に関する結論や根拠を 選択して表示し 出典をクリックすると元の記録を開きます 数値や事件の概要のような リンクで表現できない答えを 書き読みます 資料が不足すると 何が確認できないかを 簡単に説明し 単なる推測や推測で 理想的なものだと判断しません 分析中に進捗ガイドや 検索結果がないときの検索ガイドを 保持します

画面の距離は、地理的距離や関係強度スコアではありません。タイムラインタブを削除しても、保存されたインシデントデータとJSONエクスポートの`events`は保持されます。

拡大・縮小と**Fit**で画面を調整します。ドラッグ位置は現在ブラウザのケース・ビュー別に保存し、他のブラウザに座標が同期されません。

**Focus**はサイドバーを隠し、現在のグラフに画面全体を割り当てます。 **Exit focus**または`Escape`で元の画面とサイドバーの状態を復元します。選択とグラフの配置を維持し、この間も分析は継続されます。モバイルではグラフを優先表示し、活動・会話はサイドバーで開きます。

## 検索と大きなグラフ [#검색과-큰-그래프]

検索はオブジェクトの名前・タイプ・説明・属性値と関係・事象のテキストを使用します。一致した関係の両端オブジェクトもコンテキストに残ります。原文全体検索は、ケース会話の個別検索機能です。

大きなグラフはタイプ・接続範囲とページを用いて一度に表示する項目を選びます。合計数と現在の表示数を区別し、保存データやエクスポートを切り捨てることはありません。選択オブジェクトの直接接続または2段階接続で範囲を絞り込むことができます。

正確な表示セットと上限は[検索とキャッシュ](/ja/docs/algorithms/exploration)に記載されています。

## 根拠と主張確認 [#근거와-주장-확인]

オブジェクト・関係・事象を選択すると、グラフ上の詳細ウィンドウの**Details**に属性と出典が表示されます。 **根拠履歴**を開くと、同じウィンドウの履歴画面で元のセクションと引用符を確認します。保存された原文はページをめくって読むことができます。同じオブジェクトの属性値が履歴ごとに異なる場合、差を表示します。

関係の`reported`/`inferred`は根拠の表現方式であり、`claim.stance`は主張・婦人・撤回・不確実状態です。ユーザーが残すレビューステータスは別々です。どちらの表示も自動ファクト認証を意味しません。

## ケース会話とライブラリ [#케이스-대화와-보관함]

完了したケースの会話は、保存された履歴と関連する原文を見つけて回答します。選択オブジェクトをコンテキストとして使用し、引用した履歴を開いて確認できます。検索されていない、またはモデルに渡されていない素材については事実がないと判断することはできません。

ケースの会話はサイドバーの残りの高さを使い、メッセージ一覧だけをスクロールする。入力欄は下部に固定する。保管庫へ一時的に切り替えて戻っても、入力中の質問と会話状態は保持する。**Case context**で質問を、**Activity**で実際の分析進行記録を確認できる。回答の準備中は、**Thinking**にサーバーが報告した進行状態と参照記録数を表示する。回答の根拠となる原文は、展開可能な**Sources**で確認する。

ロゴ左トグルでサイドバー全体を開閉します。既存のケースを選択すると、同じサイドバーがそのケースの活動・会話に切り替わります。タイトル左のアイコンでライブラリを再度開き、別のケースを選択します。デスクトップの内部には重複する折りたたみボタンはなく、モバイルパネルは**×**、外側の領域、または`Escape`で閉じることができます。

ライブラリのごみ箱はそのケースを削除する機能なので、保存するデータは[まずバックアップ](/ja/docs/guide/import-export)してください。

タブ・ボタン・短い状態名は英語を使用します。分析の説明、根拠判定、エラーと注意内容は韓国語で表示され、原文とユーザーの質問は翻訳しません。
