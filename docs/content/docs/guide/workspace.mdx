새 분석은 `/analysis/:jobId`에서 하나의 통합 케이스로 열립니다. 공개 예제와 수동으로 가져온 그래프는 `/case/:graphId/overview`로 엽니다. 기존 `/board`·`/lanes` 링크는 그대로 사용할 수 있고, 이전 `/timeline` 링크는 Overview로 이동합니다.

## 분석 진행과 기록

홈의 **Paste source text or URLs**에 기사 주소를 한 줄에 하나씩 넣으면 온톨로지 설계 전에 공개 HTML·텍스트 본문을 읽습니다. 최대 8개 링크를 처리하며, 읽은 본문과 원래 주소를 함께 보관합니다. 일부 링크가 차단되면 읽은 자료로 계속 분석하고 누락 이유를 결과에 남깁니다. 모든 링크를 읽지 못하면 모델 호출 전에 사유를 표시하고 다시 시도할 수 있습니다. 로그인·차단·PDF·스크립트로만 표시되는 본문은 텍스트를 직접 첨부해야 할 수 있습니다.

자료를 정상적으로 검토했지만 관련 근거가 부족한 경우에는 분석 오류 대신 완료된 결과와 판단 이유를 보관합니다. 실제 읽기·모델·검증 오류는 구분해서 표시합니다.

왼쪽 패널에서 온톨로지 설계, 자료 준비, 추출, 근거 검증과 저장 단계를 확인합니다. **ACTIVITY**에는 서버가 보고한 실제 처리 메시지와 시각이 쌓이고, 처리 안내에는 현재 단계의 역할과 경과 시간이 표시됩니다. 전체 구간 수가 확정되지 않았으면 진행 비율을 표시하지 않습니다.

첫 결과 전에는 **그래프 준비 화면**을 보여줍니다. 검증·저장이 끝난 부분부터 실제 그래프가 나타나고, 뒤이어 저장된 결과도 자동으로 반영됩니다. 갱신 중에는 기존 그래프와 선택 항목을 유지합니다. 갱신에 실패하면 이전 결과와 다시 불러오기 안내를 표시합니다.

**분석 기록**은 원문 처리 구간에 대응합니다. 상단 정보 아이콘에서 **Records · N**을 선택해 **분석 기록**을 열면 객체가 없는 결과와 아직 처리하지 않은 구간을 구분할 수 있습니다. 실패·취소 후 재개하면 완료한 기록을 유지한 채 남은 구간을 처리합니다.

## 여러 케이스 함께 작업하기

분석 중에도 보관함의 **New case** 또는 상단 **NEW CASE**로 별도의 요청과 자료를 입력할 수 있습니다. 기존 분석은 서버에서 계속 실행됩니다. 홈에서는 백그라운드 분석의 상태를 확인하고, 보관함에서 원하는 케이스로 돌아갑니다. 다른 케이스로 이동하거나 새로고침해도 실행 중인 분석을 취소하지 않습니다.

기본 설정은 케이스 2개 동시 실행입니다. 실행 자리가 없으면 새 케이스는 대기하며, 실행 중·대기 중 작업은 합쳐 최대 5개까지 접수합니다. 한 케이스를 취소해도 다른 케이스의 실행과 저장 결과에는 영향을 주지 않습니다. 자료·질문·범위는 케이스별로 분리합니다.

**New case**는 입력 중인 확인 질문 초안을 초기화하고 새 입력을 엽니다. 로고를 통해 홈으로 돌아오거나 새로고침하면 아직 제출하지 않은 확인 질문 초안을 복구할 수 있습니다. 이미 서버에서 시작한 분석은 어느 동작으로도 지워지지 않습니다.

## 화면 구성

| 영역 | 표시 내용 |
| --- | --- |
| 왼쪽 사이드바 | 제목 왼쪽의 전환 아이콘으로 **Case library ↔ Current case**를 바꿉니다. 두 패널이 나란히 공간을 차지하지 않습니다. 케이스 모드에서는 분석 활동 또는 완료한 통합 케이스의 대화를 보여줍니다. |
| 중앙 작업 화면 | **Graph**의 **Overview**에서 질문에 직접 답하는 대상과 관계만 봅니다. 그래프로 답하기 어려우면 결론부터 읽을 수 있는 짧은 보고서를 표시합니다. 완료하거나 실패한 케이스의 검증 조건·판정·공백은 **Review** 탭에서 확인하며, 실패 상태는 그대로 유지합니다. |
| 상세 창 | 객체·관계를 선택하면 그래프 위에 상세 창이 부드럽게 열립니다. **Details**, **Summary**, **Sources**, 통합 케이스의 **Records**으로 내용을 전환합니다. **×**, `Escape` 또는 그래프의 빈 공간을 눌러 닫으며 그래프 크기와 선택을 유지합니다. |
| 케이스 정보 | 상단 정보 아이콘을 눌러 상세 창을 엽니다. **Summary**에서 질문, 확정한 분석 목적·범위·원하는 결과와 온톨로지를 확인합니다. 별도의 하단 설명·세션 푸터는 두지 않습니다. |

## 세 가지 보기

| 보기 | 읽는 방법 |
| --- | --- |
| Overview | 질문에 직접 답하는 대상과 관계만 간단히 표시합니다. 예를 들어 환적한 배를 찾으면 자료에 환적 관계가 명시된 선박끼리 연결합니다. 그래프로 표현할 답이 없으면 결론·핵심 근거·확인 한계를 담은 짧은 보고서를 표시합니다. |
| Board | 객체 사이의 관계를 따라갑니다. 카드를 드래그해 위치를 조정합니다. |
| Lanes | 그룹별 열로 유형과 연결을 비교합니다. |

**Overview → Board → Lanes** 순서이며 새 케이스는 Overview를 먼저 보여줍니다. Overview는 저장된 그래프에서 직접적인 답에 해당하는 관계를 골라 보여주며, 별도의 모델 실행이나 근거 진단을 요청하지 않습니다. 질문과 무관한 소유·위치 관계, 환적을 묻는 질문의 단순 조우·근접 관계, 추론·부인·철회·불확실한 관계는 답으로 제시하지 않습니다. 출처가 연결된 명시적 관계도 자료에 적힌 진술이며 자동 사실 인증은 아닙니다. 대상이나 관계를 선택하면 기존 상세 정보와 출처를 확인할 수 있습니다. 전체 그래프는 Board / Lanes, 검증 논리와 근거 공백은 Review에 남습니다.

짧은 보고서는 기존 자료에서 질문과 관련된 결론과 근거를 골라 표시하며, 출처를 누르면 원래 기록을 엽니다. 수량·사건 경위처럼 연결선으로 표현하기 어려운 답도 글로 읽을 수 있습니다. 자료가 부족하면 무엇을 확인할 수 없는지 짧게 밝히며, 단순 조우나 추정만으로 환적이 있었다고 단정하지 않습니다. 분석 중에는 진행 안내를, 검색 결과가 없을 때는 검색 안내를 유지합니다.

화면의 거리는 지리적 거리나 관계 강도 점수가 아닙니다. Timeline 탭을 제거해도 저장된 사건 데이터와 JSON 내보내기의 `events`는 유지합니다.

확대·축소와 **Fit**으로 화면을 조정합니다. 드래그 위치는 현재 브라우저의 케이스·보기별로 저장하며, 다른 브라우저에 좌표가 동기화되지는 않습니다.

**Focus**는 사이드바를 숨기고 현재 그래프에 화면 전체를 할당합니다. **Exit focus** 또는 `Escape`로 원래 화면과 사이드바 상태를 복원합니다. 선택과 그래프 배치를 유지하며, 이 동안에도 분석은 계속됩니다. 모바일에서는 그래프를 우선 표시하고 활동·대화는 사이드바에서 엽니다.

## 검색과 큰 그래프

검색은 객체의 이름·유형·설명·속성 값과 관계·사건의 텍스트를 사용합니다. 일치한 관계의 양 끝 객체도 맥락으로 남습니다. 원문 전체 검색은 케이스 대화의 별도 검색 기능입니다.

큰 그래프는 유형·연결 범위와 페이지를 이용해 한 번에 표시할 항목을 고릅니다. 전체 개수와 현재 표시 개수를 구분하며 저장 데이터나 내보내기를 잘라내지는 않습니다. 선택 객체의 직접 연결이나 두 단계 연결로 범위를 좁힐 수 있습니다.

정확한 표시 집합과 상한은 [검색과 캐시](/docs/algorithms/exploration)에 설명되어 있습니다.

## 근거와 주장 확인

객체·관계·사건을 선택하면 그래프 위 상세 창의 **Details**에 속성과 출처가 표시됩니다. **근거 기록**을 열면 같은 창의 기록 화면에서 원래 구간과 인용문을 확인합니다. 저장된 원문은 페이지를 넘겨 읽을 수 있습니다. 같은 객체의 속성 값이 기록마다 다르면 차이를 표시합니다.

관계의 `reported`/`inferred`는 근거의 표현 방식이고, `claim.stance`는 주장·부인·철회·불확실 상태입니다. 사용자가 남기는 검토 상태는 별도입니다. 어느 표시도 자동 사실 인증을 뜻하지 않습니다.

## 케이스 대화와 보관함

완료한 케이스의 대화는 저장된 기록과 관련 원문을 찾아 답변합니다. 선택 객체를 맥락으로 사용하며 인용한 기록을 열어 확인할 수 있습니다. 검색되지 않거나 모델에 전달되지 않은 자료에 대해 사실이 없다고 단정할 수는 없습니다.

케이스 대화는 사이드바의 남은 높이를 채우며 메시지 목록만 별도로 스크롤합니다. 입력창은 하단에 유지됩니다. 보관함으로 잠시 전환했다가 현재 케이스로 돌아와도 작성 중인 질문과 대화 상태를 유지합니다. **Case context**에서 질문을, **Activity**에서 실제 분석 진행 기록을 펼쳐 확인합니다. 답변 준비 중에는 **Thinking**에 서버가 보고한 진행 상태와 참조 기록 수를 표시합니다. 답변의 원문 근거는 접힌 **Sources**를 열어 확인할 수 있습니다.

로고 왼쪽 토글로 사이드바 전체를 열고 닫습니다. 기존 케이스를 선택하면 같은 사이드바가 해당 케이스의 활동·대화로 전환됩니다. 제목 왼쪽 아이콘으로 보관함을 다시 열어 다른 케이스를 선택합니다. 데스크톱 내부에는 중복 접기 버튼이 없으며, 모바일 패널은 **×**, 바깥 영역 또는 `Escape`로 닫을 수 있습니다.

보관함의 휴지통은 해당 케이스를 삭제하는 기능이므로 보관할 데이터는 [먼저 백업](/docs/guide/import-export)하세요.

탭·버튼·짧은 상태 이름은 영어를 사용합니다. 분석 설명, 근거 판정, 오류와 주의 내용은 한국어로 표시하며 원문과 사용자 질문은 번역하지 않습니다.
