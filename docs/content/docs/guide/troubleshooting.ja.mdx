## vite コマンドが見つかりません [#vite-명령을-찾을-수-없음]

アプリを実行する端末に依存関係をインストールします。 Windows PowerShellでWSL用`node_modules`を使用すると、`vite.cmd`やWindowsネイティブモジュールがない可能性があります。

```powershell
npm ci --include=dev --include=optional
npm run dev
```

アプリはNode.js**22.17以上**が必要です。 WindowsとWSLを切り替えるときは、既存のサーバーをシャットダウンして新しい環境で再インストールしてください。現在、root アプリコマンドには自動依存リカバリ手順はありません。

## ドキュメントのnextコマンドが見つかりません [#문서의-next-명령을-찾을-수-없음]

ドキュメントはアプリと依存関係が別々です。プロジェクトのルートで実行します。

```bash
npm run docs:install
npm run docs:dev
```

文書アドレスは`http://127.0.0.1:3001`です。 docs 実行・ビルド・タイプ検査にはオペレーティングシステム別依存性確認段階があり、未インストール・環境切り替え時に再インストールします。失敗した場合は、npmのネットワーク・権限エラーを確認してください。

## 新しい分析が開始されない [#새-분석이-시작되지-않음]

アプリを実行する同じOS・ユーザーアカウントで確認します。

```bash
npm run codex:login
npm run codex:status
```

最終範囲確認画面で**この範囲で分析を開始**を押すと、実際のジョブが作成されます。質問だけ入れたらオントロジーだけ設計するのが正常です。オブジェクト・関係には根拠資料が必​​要です。

Jevキーはオプションです。 **Jev選択判定準備済み**はサーバーにキーがあることを意味し、実際の権限・ネットワーク・使用量確認は呼び出し時に行われます。 Foundry環境変数は、現在の分析パスには必要ありません。

## 資料の読み取りとサイズエラー [#자료-읽기와-크기-오류]

| 症状 | 確認する内容 |
| --- | --- |
| 元の素材が読めない | UTF-8テキストであることを確認してください。 PDF・写真・Office・圧縮ファイルはまず内容抽出 |
| アップロードが大きすぎます | `CLUEVIA_MAX_UPLOAD_MB`、プロキシ制限、サーバースペースの確認 |
| インライン documents 長さを超える | APIインライン本文は資料別50,000文字・合計150,000字。大きな本文はファイルアップロードを使用 |
| 資料数超過 | インライン素材とアップロードIDを合わせて最大10個 |
| グラフJSONのインポートに失敗しました | 一般資料JSONと完成したGraphDocument区分。インポートファイルは2MB以下 |

ネイティブファイルのアップロードは、アプリサイズの上限はデフォルトではありませんが、実行環境のリソース制限までなくなるわけではありません。

## 分析失敗・キャンセル・更新 [#분석-실패취소새로고침]

分析画面をもう一度開き、サーバーの操作を照会します。 **残りの区間に続いて分析**で完了していない区間を再開できます。完了した部分結果は保存されます。

設計段階のタイムアウトと文書間のタイムアウトは異なる段階です。処理履歴の失敗手順を確認してください。繰り返し失敗は、そのステップのサーバーエラーと入力形式を確認します。ジョブ待ち行列がいっぱいになると、既存のジョブが終了した後に再要求します。

## サーバー接続と保存ケース [#서버-연결과-저장된-케이스]

`dist/`だけ静的にホストすると、生成・保存APIがありません。ビルド後、`npm start`で画面とAPIを一緒に実行します。 LAN接続には、サーバーの`CLUEVIA_ACCESS_TOKEN`設定とWeb画面の接続キーの入力が必要です。

ケースが見つからない場合は、同じサーバー・データディレクトリに接続したことを確認してください。ブラウザの保存代替としてインポートされたグラフは、対応するブラウザストアにのみあります。 [保存とインポート](/ja/docs/guide/import-export)を参照してください。

## Overviewで結果が見つかりません [#overview에서-결과를-찾지-못함]

Overview は、保存済みグラフから質問に直接答える明示的な関係だけを選んで表示する。推論、否認、撤回、不確実な関係、または質問に答えない周辺関係しかない場合は、結果が見つからないことを示す。例えば、二隻が接近した記録だけでは、実際の積み替えを示せない。これは現資料から答えが得られないという意味であり、出来事が起きなかったことの証明ではない。全記録は **Board / Lanes**、論理と根拠の欠落は **Review** で確認する。旧 Timeline の URL は Overview に転送されるが、事件データはエクスポート JSON に残る。
