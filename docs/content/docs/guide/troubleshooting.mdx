## vite 명령을 찾을 수 없음

앱을 실행할 터미널에서 의존성을 설치하세요. Windows PowerShell에서 WSL용 `node_modules`를 사용하면 `vite.cmd`나 Windows 네이티브 모듈이 없을 수 있습니다.

```powershell
npm ci --include=dev --include=optional
npm run dev
```

앱은 Node.js **22.17 이상**이 필요합니다. Windows와 WSL 사이를 바꿀 때는 기존 서버를 종료하고 새 환경에서 다시 설치하세요. 현재 루트 앱 명령에 자동 의존성 복구 단계는 없습니다.

## 문서의 next 명령을 찾을 수 없음

문서는 앱과 의존성이 별도입니다. 프로젝트 루트에서 실행합니다.

```bash
npm run docs:install
npm run docs:dev
```

문서 주소는 `http://127.0.0.1:3001`입니다. docs 실행·빌드·타입 검사에는 운영체제별 의존성 확인 단계가 있으며 미설치·환경 전환 시 다시 설치합니다. 실패하면 npm의 네트워크·권한 오류를 확인하세요.

## 새 분석이 시작되지 않음

앱을 실행하는 같은 OS·사용자 계정에서 확인합니다.

```bash
npm run codex:login
npm run codex:status
```

최종 범위 확인 화면에서 **이 범위로 분석 시작**을 눌러야 실제 작업이 만들어집니다. 질문만 넣었다면 온톨로지만 설계하는 것이 정상입니다. 객체·관계에는 근거 자료가 필요합니다.

Jev 키는 선택 사항입니다. **Jev 선택 판정 준비됨**은 서버에 키가 있다는 뜻이며 실제 권한·네트워크·사용량 확인은 호출 때 이루어집니다. Foundry 환경 변수는 현재 분석 경로에 필요하지 않습니다.

## 자료 읽기와 크기 오류

| 증상 | 확인할 내용 |
| --- | --- |
| 원본 자료를 읽을 수 없음 | UTF-8 텍스트인지 확인. PDF·사진·Office·압축 파일은 먼저 내용 추출 |
| 업로드가 너무 큼 | `CLUEVIA_MAX_UPLOAD_MB`, 프록시 제한, 서버 공간 확인 |
| 인라인 documents 길이 초과 | API 인라인 본문은 자료별 50,000자·합계 150,000자. 큰 본문은 파일 업로드 사용 |
| 자료 개수 초과 | 인라인 자료와 업로드 ID를 합해 최대 10개 |
| 그래프 JSON 가져오기 실패 | 일반 자료 JSON과 완성된 GraphDocument 구분. 가져오기 파일은 2MB 이하 |

원시 파일 업로드는 앱 크기 상한이 기본적으로 없지만 실행 환경의 자원 제한까지 없어지는 것은 아닙니다.

## 분석 실패·취소·새로고침

분석 화면을 다시 열어 서버 작업을 조회합니다. **남은 구간 이어서 분석**으로 완료하지 않은 구간을 재개할 수 있습니다. 완료한 부분 결과는 보존됩니다.

설계 단계 시간 초과와 문서 구간 시간 초과는 서로 다른 단계입니다. 처리 내역에서 실패 단계를 확인하세요. 반복 실패는 해당 단계의 서버 오류와 입력 형식을 확인합니다. 작업 대기열이 가득 차면 기존 작업이 끝난 뒤 다시 요청합니다.

## 서버 연결과 저장된 케이스

`dist/`만 정적으로 호스팅하면 생성·저장 API가 없습니다. 빌드 후 `npm start`로 화면과 API를 함께 실행합니다. LAN 연결에는 서버의 `CLUEVIA_ACCESS_TOKEN` 설정과 웹 화면의 연결키 입력이 필요합니다.

케이스를 찾지 못하면 같은 서버·데이터 디렉터리에 연결했는지 확인하세요. 브라우저 저장 대안으로 가져온 그래프는 해당 브라우저 저장소에만 있습니다. [저장과 가져오기](/docs/guide/import-export)를 참고하세요.

## Overview에서 결과를 찾지 못함

Overview는 저장된 그래프에서 질문에 직접 답하는 명시적 관계만 골라 표시합니다. 추론·부인·철회·불확실한 관계나 질문에 답하지 않는 주변 관계만 있으면 찾지 못했다는 글을 보여줍니다. 예를 들어 두 배가 근접했다는 기록만으로 실제 환적했다고 표시하지 않습니다. 이는 현재 자료에서 답을 찾지 못했다는 뜻이며 사건이 발생하지 않았다는 판정은 아닙니다. **Board / Lanes**에서 전체 기록을 살펴보고 **Review**에서 근거와 공백을 확인하세요. 이전 Timeline 주소는 Overview로 이동하며 사건 데이터는 내보낸 JSON에 유지됩니다.
