## 找不到 Vite 命令 [#vite-명령을-찾을-수-없음]

在实际运行应用的终端环境安装依赖。Windows PowerShell 若使用了为 WSL 安装的 `node_modules`，可能缺少 `vite.cmd` 或 Windows 原生模块。

```powershell
npm ci --include=dev --include=optional
npm run dev
```

应用程序需要Node.js **22.17或更高**. 在Windows和 WSL 关闭旧服务器，重新安装在新环境中。 目前，根应用程序命令中没有自动修复依赖性步骤。

## 文档找不到 Next 命令 [#문서의-next-명령을-찾을-수-없음]

文件与应用程序有不同的依赖性。 从项目根源开始运行。

```bash
npm run docs:install
npm run docs:dev
```

文档地址为 `http://127.0.0.1:3001`。文档的启动、构建和类型检查均包含按操作系统检查依赖的步骤；未安装依赖或切换环境时，会重新安装。若失败，请检查 npm 报告的网络或权限错误。

## 新分析没有开始 [#새-분석이-시작되지-않음]

在运行应用的同一操作系统与用户账户下检查登录状态。

```bash
npm run codex:login
npm run codex:status
```

必须在最终范围确认页面点击 **Start Analysis with this Scope**，才能创建实际任务。仅输入问题时，通常只进行本体设计；生成对象与关系需要证据资料。

Jev 密钥为可选项。**Jev 选择性判定已就绪**仅表示服务器中存在密钥；实际权限、网络与用量会在调用时检查。当前分析路径不需要 Foundry 环境变量。

## 数据读取和尺寸错误 [#자료-읽기와-크기-오류]

| 症状 | 检查什么 |
| --- | --- |
| 无法读取原始资料 | 检查是否为 UTF-8 文本。PDF、图片、Office 与压缩文件须先提取内容 |
| 上传过大 | 检查 `CLUEVIA_MAX_UPLOAD_MB`、代理限制与服务器剩余空间 |
| 内联文档超长 | API 内联文本每份最多 50,000 字符，总计最多 150,000 字符；更大内容应使用文件上传 |
| 资料数量超限 | 内联资料与上传 ID 合计最多 10 项 |
| 图 JSON 导入失败 | 区分普通资料 JSON 与完整 GraphDocument；导入文件须符合 2MB 限制 |

原始文件上传本质上没有应用程序大小的上限，但这并不消除执行环境的资源限制。

## 分析失败/取消/更新 [#분석-실패취소새로고침]

重新打开分析界面，核查服务器任务状态。可通过 **Resume remaining analysis** 恢复未完成部分；已保存的局部结果会保留。

设计阶段超时与文档区段超时属于不同阶段，应在处理日志中核查失败位置。持续失败时检查服务器错误和输入格式。队列已满时，待已有任务完成后再提交。

## 服务器连接和保存案例 [#서버-연결과-저장된-케이스]

仅静态托管 `dist/` 不会提供生成及存储 API。构建完成后，使用 `npm start` 同时运行界面与 API。局域网连接还需要服务器设置 `CLUEVIA_ACCESS_TOKEN`，并在网页输入连接密钥。

找不到案例时，先确认是否连接到同一服务器和数据目录。选择浏览器保存的导入图仅存在于该浏览器存储中。参见[保存与导入](/zh/docs/guide/import-export)。

## 在概述中没有发现结果 [#overview에서-결과를-찾지-못함]

Overview 从已保存图中选取直接回答问题的明确关系。若只有推断、否认、撤回、不确定关系，或与答案无关的周边关系，则显示未找到结果。例如，两船接近的记录不能证明实际转运。这表示当前资料未提供答案，并不表示事件没有发生。可在 **Board / Lanes** 查看完整记录，在 **Review** 核查逻辑与证据缺口。旧时间轴地址转至 Overview；事件数据仍保留在导出 JSON 中。
