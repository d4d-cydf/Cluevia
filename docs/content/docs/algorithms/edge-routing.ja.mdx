`edgeGeometry`は、1つの関係とカード座標、Lanesかどうか、関係配列の順番を入力し、SVGパスとラベルの中心を返します。両端の座標がない場合、そのパスは作成されません。

## カードの境界に両端を接続する [#카드-경계에-양-끝을-연결한다]

カード中心差を`(dx, dy)`とすると、カード半幅・半高さに3pxを加えて接続位置を求めます。

```text
factor = min(94 / max(1, abs(dx)), 40 / max(1, abs(dy)))
A      = source + (dx, dy) × factor
B      = target - (dx, dy) × factor
```

カードサイズは182×74pxです。一般的な関係は、AとBの中央から垂直方向に制御点Cを移動して2次ベジェ曲線を作成します。

```text
bend = 관계 순번 % 3이 0이면 16, 아니면 -16
C    = (A + B) / 2 + 수직 단위 벡터 × bend
P(t) = (1 - t)² A + 2(1 - t)t C + t² B
label = P(0.5) = (A + 2C + B) / 4
```

曲げは、同じオブジェクトのペアの数ではなく、全体の関係配列の順番で決まります。したがって、同じ方向の平行関係が同じパスとラベルの位置を共有できます。

## 同じ熱と自己関係 [#같은-열과-자기-관계]

| 種類 | パスとラベル |
| --- | --- |
| Lanes で横方向の差が 1px 未満 | 配列中の順番の奇偶に応じて、カードの左または右へ 125px 離した制御点を用いる三次曲線。ラベルの x は制御点の x、y は両カードの中間値とする |
| 自分自身を指す関係 | カードの上の3次曲線。両端は中心からx± 34 , y− 37 ;制御点はx± 65 , y− 105  |
| 自己関係ラベル | カード中心でy−83 |

同じオブジェクトの自己関係が複数ある場合は、同じループを使用します。経路計算後、矢印は関係の`source → target`方向に配置されます。

## ラベル表示ルール [#라벨-표시-규칙]

ラベルは154×22pxのSVG`foreignObject`領域に表示します。関係が65個以下の場合はすべて表示し、それより多い場合は選択した関係と主要関係トグルで強調した関係のラベルのみ表示します。関係自体は選択でき、SVGタイトルにも名前を提供します。

`reported`/`inferred`と関係の主張態度は線のスタイルに反映されます。婦人・撤回・不確実状態はラベルにも表示できます。表示方式が主張の真実かどうかを判断するものではありません。

## 複雑さと限界 [#복잡도와-한계]

座標 Map ルックアップを平均定数時間で見ると、関係 1 つの幾何計算は `O(1)`、全体は `O(E)` です。テキストレンダリングコストは別途です。

現在の実装は、カード・他のラベルの遮蔽面積を最適化したり、経路交差を避ける探索を行いません。密なグラフでは、オブジェクトをドラッグするか、[ナビゲーションを絞り込む](/ja/docs/algorithms/exploration)の根拠を読みます。
