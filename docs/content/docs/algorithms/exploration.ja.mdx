title: "検索とキャッシュ"
description: "選択周辺を拡張し、検索・ページで表示セットを決め、画面計算とサーバー抽出結果を再利用します。"
---

グラフナビゲーションは、保存したデータから表示する部分を選択します。検索・表示切り替え・拡大・縮小自体はモデルを再呼び出ししません。ケース会話の原文検索とグラフ画面検索は別機能です。

## 大きなグラフの表示セットを作成する [#큰-그래프의-표시-집합을-만든다]

オブジェクト200個、関係1,000個、事件500個のいずれかを超えると、`GraphRenderer`が`exploreGraph`の部分グラフを表示します。完全な保存データとエクスポートには、元のアイテムを保持します。

### 選択を開始点に周囲を広げる [#선택을-시작점으로-주변을-확장한다]

オブジェクト選択はそのオブジェクト、関係選択は両端オブジェクト、イベント選択は関連オブジェクトを開始セットとして使用します。接続範囲が 1 または 2 の場合は、各ステップごとに関係全体を見て、前のセットに到達する両端を追加します。

```text
A → B → C, 시작 집합 {A}
1단계: {A, B}
2단계: {A, B, C}
```

ナビゲーションでは、関係の方向に関係なく、ネイバーを拡張します。各ステップは前のセットのコピーに基づいているため、1回の巡回で複数のステップが拡張されるわけではありません。深さ0は完全なリストです。

### 検索とタイプ条件を適用する [#검색과-유형-조건을-적용한다]

検索語とオブジェクトの名前・タイプ・説明・属性値は、NFKC正規化と小文字変換後の部分文字列で比較します。関係とイベントの検索対象は次のとおりです。

| アイテム | 検索文字列 |
| --- | --- |
| 関係 | 名前・説明 |
| イベント | 名前・説明・開始日 |

関係やイベントが一致すると、関連オブジェクトも候補に含まれます。現在の関係・事象文字列には小文字変換のみ適用するため、オブジェクトと正規化方式がまったく同じではありません。

選択した開始オブジェクトはフィルタに関係なく残ります。接続範囲を指定した場合、そのネイバーはクエリが直接一致しなくても文脈のままですが、タイプフィルタは適用されます。

### ページを作成して関係を制限する [#페이지를-만들고-관계를-제한한다]

デフォルトのオブジェクト表示上限は200個で、関数引数には20–300個の範囲を許可します。開始オブジェクトを最大20個まで固定し、残りのスペースをページに分割します。

選択したオブジェクトセット内の両端を持つ関係を集めて選択関係と検索一致関係を優先ソートした後、最大1,000個表示します。イベントは、関連オブジェクトの1つが表示セットに含まれている場合に含め、最大500個表示します。隠された関係の数を案内し、ソースを削除しません。

## キャンバスの中では一致文脈を強調する [#캔버스-안에서는-일치-맥락을-강조한다]

小さなグラフまたは投影されたグラフでは、`GraphCanvas`は検索クエリに一致するオブジェクト、一致関係の両端、一致イベントのオブジェクトを鮮明に表示します。残りはぼやけて表示されます。キャンバスの文字列比較は小文字変換ベースであり、投影関数のNFKC処理と区別されます。

関係の両端が一致セットにある場合、その関係も鮮明に残ります。画面のマッチ数には、このようなコンテキストオブジェクトを含めることができます。主な関係切り替えは`highlighted`マークを使用し、最短パスを計算しません。

オブジェクトが100個を超えると、画面の周囲の余白を超えたカードのDOMレンダリングは省略されます。選択・ドラッグ中のカードは維持し、関係線全体を同じように仮想化するわけではありません。

## 画面計算と配置状態を再利用する [#화면-계산과-배치-상태를-재사용한다]

| スーダン | 保管する |
| --- | --- |
| React `useMemo` | グラフ・ビューなど依存性が維持されている間、配置、IDマップ、ナビゲーション投影 |
| `priorScene` | 同じボードにオブジェクトが追加されたときの既存の座標 |
| `localStorage` | グラフID・ビュー別手動ドラッグ座標 |

現在の実装には、グラフごとのグローバル`WeakMap`レイアウトキャッシュはありません。タイムラインの配置は、グラフが変わると計算され、基本シーンも一緒に計算されるため、ビューを開くときにその計算のみを実行すると仮定しないでください。

初期倍率はシーン幅に合わせた値を65–100％に制限します。 Fitはシーンの幅・高さがビューポートで28px余白を置いて入るように計算し、2–100％に制限します。通常のズーム範囲は2–180％です。

## サーバーの抽出キャッシュと原文検索 [#서버의-추출-캐시와-원문-검색]

[データ構造化](/ja/docs/algorithms/extraction)の7日目のキャッシュはモデル抽出結果を再利用します。画面座標キャッシュとは別であり、オントロジー・資料・処理設定などが変わるとキーも変わります。

ケース会話は、アーカイブ原文の逆索引を使用します。韓国語の2文字の断片、調査の削除、識別子と制限された同義語を検索候補に反映し、関連原文を見つけてモデルに渡します。意味 埋め込み検索は使用しません。同義語が同じであるため、オブジェクトをマージしません。

## コストと実装 [#비용과-구현]

選択周囲の拡張は深さ`D`、関係数`E`に対して`O(DE)`です。検索はテキストと参照を盗み、関係・事件候補の並べ替えには最悪の`O(E log E + T log T)`がかかります。ページに表示する数を制限しても、候補検索はグラフ全体を対象としています。

-  [src/lib/graph-exploration.ts](https://github.com/d4d-cydf/Cluevia/blob/main/src/lib/graph-exploration.ts) ,  [画面テスト](https://github.com/d4d-cydf/Cluevia/blob/main/tests/analysis-improvements.spec.ts) グラフの検索画面です.
- [GraphRenderer.tsx](https://github.com/d4d-cydf/Cluevia/blob/main/src/components/graph/GraphRenderer.tsx)：キャンバス強調・配置状態・画面外カード処理
- [server/evidence-search.ts](https://github.com/d4d-cydf/Cluevia/blob/main/server/evidence-search.ts)：原文検索トークン
- [server/analysis-pipeline.ts](https://github.com/d4d-cydf/Cluevia/blob/main/server/analysis-pipeline.ts)：抽出キャッシュ
