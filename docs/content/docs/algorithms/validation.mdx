Cluevia의 검증은 **추출 근거 검사**와 **그래프 계약 검사**로 나뉩니다. 모델 추출은 두 계층을 거치며, 완성된 JSON 가져오기는 그래프 계약을 검사합니다.

| 검증기 | 입력 | 확인하는 것 |
| --- | --- | --- |
| `parseExtraction` | 추출 결과, 원문, 온톨로지 | 유형·속성·관계 제약, 인용문, 식별 근거 |
| `parseGraphDocument` | 알 수 없는 JSON 값 | 필드·크기·날짜·ID·참조 |

## 원문과 추출 결과를 대조한다

`server/ontology.ts`는 인용의 `documentId`가 입력 자료에 있는지 확인하고, 해당 본문에 `quote` 문자열이 정확히 포함되는지 검사합니다. 식별자는 인용문에 존재해야 하며, 온톨로지에서 근거 기반 기본 키로 정한 값에도 별도 확인을 적용합니다.

예를 들어 원문이 `고객 번호 C-17`인데 모델이 `C-18`을 식별자로 반환하면 해당 인용으로 통과할 수 없습니다. 같은 이름이 등장해도 이름만으로 동일 객체임을 입증하지 않습니다.

저장 시 인용의 UTF-16 시작·끝 위치와 분석 텍스트의 SHA-256을 기록합니다. 동일한 문구가 반복되면 위치 후보와 모호함을 보존합니다. 해시는 텍스트 식별값이며 사실 인증 값은 아닙니다.

## 허용된 그래프 필드로 새 객체를 만든다

`parseGraphDocument`는 실행 중 타입·길이·개수·형식을 검사하고 필요한 필드만 새 객체로 구성합니다. 알 수 없는 필드는 복사하지 않습니다. 문자열은 길이를 검사한 뒤 양쪽 공백을 제거합니다.

```text
최상위 객체 · 스키마 버전 · 작성 경로 · 그래프 ID
  → groups / sources / nodes / edges / events / findings 구성
  → 종류별 ID 집합과 중복 검사
  → 그룹 · 객체 · 관계 · 출처 참조 검사
  → 온톨로지 ID·버전 및 나머지 메타데이터 확인
```

검사는 첫 오류에서 중단합니다. 선택 필드는 생략하며, 일반 선택 필드에 `null`을 넣는 것은 생략과 다릅니다. 단, `claim` 내부의 nullable 필드는 계약에 따라 `null`을 허용합니다.

## ID 집합으로 중복과 참조를 검사한다

| 참조 | 검사할 ID 집합 |
| --- | --- |
| `node.group` | 그룹 |
| `edge.source`, `edge.target`, `event.nodeIds`, `finding.nodeIds` | 객체 |
| `finding.edgeIds` | 관계 |
| 모든 `sourceIds` | 출처 |

각 배열 내부의 ID는 중복될 수 없습니다. 서로 다른 종류의 배열 사이에는 전역 중복 검사를 하지 않습니다. 참조 배열도 내부 중복을 허용하지 않습니다.

객체 목록에 A만 있는데 관계의 끝점이 B이면 `edge 관계ID: 존재하지 않는 ID: B`처럼 실패합니다. 자기 관계와 같은 객체 쌍의 여러 관계는 허용합니다.

## 날짜와 확장 필드를 확인한다

날짜는 `YYYY-MM-DD` 또는 초·시간대가 포함된 ISO 시각입니다. 정규식과 `Date.parse`를 확인하고 날짜 부분을 UTC 자정으로 왕복 변환해 `2026-02-30` 같은 잘못된 날짜를 거릅니다. 기간의 종료가 시작보다 빠르면 거절합니다.

| 필드 | 규칙 |
| --- | --- |
| `ontologyId`, `ontologyVersion` | 함께 존재해야 함. 버전은 1 이상의 안전 정수 |
| `source.contentHash`, `source.sourceFamily` | 소문자 16진수 64자리 SHA-256 형태 |
| `edge.claim` | 주장 태도, 주체, 유효 기간, 발행일과 재인용 출처 검사 |

기간 비교와 [시간축 좌표](/docs/algorithms/timeline)는 시간대 오프셋을 반영한 절대 시각을 사용합니다.

## 단일 그래프와 통합 케이스의 경계

단일 `GraphDocument`는 객체 200개, 관계 500개, 사건 300개까지 허용합니다. `parseGraphText`는 JSON의 UTF-8 크기도 2,000,000바이트 이하인지 확인합니다.

여러 분석 기록을 합친 케이스는 별도 서버 투영 결과입니다. 단일 추출 제한을 전체 케이스에 다시 적용하지 않습니다. `.case.json` 내보내기도 일반 그래프 JSON과 다른 형식입니다.

가져오기는 원래 파일을 먼저 검증한 뒤 `origin`을 `imported`로 바꾸어 저장합니다. ID나 누락된 참조를 임의로 추정해 검증을 우회하지 않습니다.

## 복잡도와 한계

그래프 항목 수를 `N`, 참조 수를 `R`, 검사·복사하는 텍스트 양을 `S`라 하면, 평균 상수 시간의 집합 조회를 가정할 때 그래프 계약 검사는 `O(N + R + S)`로 볼 수 있습니다. 원문 인용 검사의 문자열 검색 비용은 별도입니다.

검증 성공은 구조와 원문 인용이 검사 규칙을 따른다는 뜻입니다. 출처의 진위, 추론의 타당성, 사실 누락이나 전체 병합 정확성까지 판정하지는 않습니다.
