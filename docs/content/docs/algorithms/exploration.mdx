그래프 탐색은 저장된 데이터에서 표시할 부분을 고릅니다. 검색·보기 전환·확대·축소 자체는 모델을 다시 호출하지 않습니다. 케이스 대화의 원문 검색과 그래프 화면 검색은 별도 기능입니다.

## 큰 그래프의 표시 집합을 만든다

객체 200개, 관계 1,000개, 사건 500개 중 어느 하나라도 넘으면 `GraphRenderer`가 `exploreGraph`의 부분 그래프를 표시합니다. 전체 저장 데이터와 내보내기에는 원래 항목을 유지합니다.

### 선택을 시작점으로 주변을 확장한다

객체 선택은 그 객체, 관계 선택은 양 끝 객체, 사건 선택은 관련 객체들을 시작 집합으로 사용합니다. 연결 범위가 1 또는 2이면 각 단계마다 전체 관계를 훑어 이전 집합에 닿는 양 끝을 추가합니다.

```text
A → B → C, 시작 집합 {A}
1단계: {A, B}
2단계: {A, B, C}
```

탐색에서는 관계 방향에 상관없이 이웃을 확장합니다. 각 단계가 이전 집합의 복사본을 기준으로 하므로 한 번의 순회에서 여러 단계가 확장되지는 않습니다. 깊이 0은 전체 목록입니다.

### 검색과 유형 조건을 적용한다

검색어와 객체의 이름·유형·설명·속성 값은 NFKC 정규화와 소문자 변환 후 부분 문자열로 비교합니다. 관계와 사건의 검색 대상은 다음과 같습니다.

| 항목 | 검색 문자열 |
| --- | --- |
| 관계 | 이름·설명 |
| 사건 | 이름·설명·시작 날짜 |

관계나 사건이 일치하면 관련 객체도 후보에 포함합니다. 현재 관계·사건 문자열에는 소문자 변환만 적용하므로 객체와 정규화 방식이 완전히 같지는 않습니다.

선택한 시작 객체는 필터와 무관하게 남습니다. 연결 범위를 지정했으면 해당 이웃은 검색어가 직접 일치하지 않아도 맥락으로 남지만, 유형 필터는 적용됩니다.

### 페이지를 만들고 관계를 제한한다

기본 객체 표시 상한은 200개이며 함수 인수로는 20–300개 범위를 허용합니다. 시작 객체를 최대 20개까지 고정하고 나머지 공간을 페이지로 나눕니다.

선택된 객체 집합 안의 양 끝을 가진 관계를 모아 선택 관계와 검색 일치 관계를 우선 정렬한 뒤 최대 1,000개 표시합니다. 사건은 관련 객체 중 하나가 표시 집합에 있으면 포함하고 최대 500개 표시합니다. 숨겨진 관계 수를 안내하며 원본을 삭제하지 않습니다.

## 캔버스 안에서는 일치 맥락을 강조한다

작은 그래프 또는 투영된 그래프에서 `GraphCanvas`는 검색어와 일치한 객체, 일치 관계의 양 끝, 일치 사건의 객체를 선명하게 표시합니다. 나머지는 흐리게 표시합니다. 캔버스의 문자열 비교는 소문자 변환 기반이며 투영 함수의 NFKC 처리와 구분됩니다.

관계의 양 끝이 일치 집합에 있으면 그 관계도 선명하게 남습니다. 화면의 matches 수에는 이런 맥락 객체가 포함될 수 있습니다. 주요 관계 토글은 `highlighted` 표시를 사용하며 최단 경로를 계산하지 않습니다.

객체가 100개를 넘으면 화면 주변 여백을 벗어난 카드의 DOM 렌더링을 생략합니다. 선택·드래그 중인 카드는 유지하며, 관계선 전체를 같은 방식으로 가상화하는 것은 아닙니다.

## 화면 계산과 배치 상태를 재사용한다

| 수단 | 보관하는 것 |
| --- | --- |
| React `useMemo` | 그래프·보기 등 의존성이 유지되는 동안 배치, ID Map, 탐색 투영 |
| `priorScene` | 같은 Board에 객체가 추가될 때 기존 좌표 |
| `localStorage` | 그래프 ID·보기별 수동 드래그 좌표 |

현재 구현에는 그래프별 전역 `WeakMap` 레이아웃 캐시가 없습니다. Timeline 배치는 그래프가 바뀌면 계산하고, 기본 장면도 함께 계산하므로 보기를 열 때 해당 계산만 실행한다고 가정하면 안 됩니다.

초기 배율은 장면 폭에 맞춘 값을 65–100%로 제한합니다. Fit은 장면의 폭·높이가 뷰포트에서 28px 여백을 두고 들어오도록 계산하며 2–100%로 제한합니다. 일반 줌 범위는 2–180%입니다.

## 서버의 추출 캐시와 원문 검색

[자료 구조화](/docs/algorithms/extraction)의 7일 캐시는 모델 추출 결과를 재사용합니다. 화면 좌표 캐시와 별개이며, 온톨로지·자료·처리 설정 등이 바뀌면 키도 달라집니다.

케이스 대화는 보관 원문의 역색인을 사용합니다. 한국어 2글자 조각, 조사 제거, 식별자와 제한된 동의어를 검색 후보에 반영하고 관련 원문을 찾아 모델에 전달합니다. 의미 임베딩 검색은 사용하지 않습니다. 동의어가 같다는 이유로 객체를 병합하지 않습니다.

## 비용과 구현

선택 주변 확장은 깊이 `D`, 관계 수 `E`에 대해 `O(DE)`입니다. 검색은 텍스트와 참조를 훑고, 관계·사건 후보 정렬에는 최악 `O(E log E + T log T)`가 듭니다. 페이지에 표시하는 수를 제한해도 후보 검색은 전체 그래프를 대상으로 합니다.

- [src/lib/graph-exploration.ts](https://github.com/d4d-cydf/Cluevia/blob/main/src/lib/graph-exploration.ts), [화면 테스트](https://github.com/d4d-cydf/Cluevia/blob/main/tests/analysis-improvements.spec.ts): 큰 그래프의 탐색 화면
- [GraphRenderer.tsx](https://github.com/d4d-cydf/Cluevia/blob/main/src/components/graph/GraphRenderer.tsx): 캔버스 강조·배치 상태·화면 밖 카드 처리
- [server/evidence-search.ts](https://github.com/d4d-cydf/Cluevia/blob/main/server/evidence-search.ts): 원문 검색 토큰
- [server/analysis-pipeline.ts](https://github.com/d4d-cydf/Cluevia/blob/main/server/analysis-pipeline.ts): 추출 캐시
