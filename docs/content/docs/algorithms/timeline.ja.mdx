---
title: "時系列の配置"
description: "インシデントの絶対時間を水平座標に投影し、オブジェクトごとの行で重ならないトラックを選択します。"
---

`timelineLayout`はグラフの事件を日付順に整列して行・トラック・期間バーと目盛りを計算します。 `events`が空の場合、日付を推定せずに空の時間軸を表示します。

## 1。時間帯を反映して並べ替える [#1-시간대를-반영해-정렬한다]

開始日と終了日を`Date.parse`で読みます。開始時刻の昇順で並べ替え、同率はIDの`localeCompare`で決まります。

```text
2017-08-12T01:30:00+09:00
→ 2017-08-11T16:30:00Z와 같은 좌표
```

時間軸とイベントカードの日付は、UTC基準の日単位で表示されます。したがって、原文のタイムゾーンの日付と一日の差がある可能性があり、同じ日の異なる時刻も同じ日付ラベルとして表示されます。

## 2。時刻を水平座標で投影する [#2-시각을-가로-좌표로-투영한다]

すべての開始・終了時刻の最低値と最コメント値を求めます。事件数を`T`とすると、以下を使用します。

```text
span  = max(86,400,000ms, maxTime - minTime)
width = max(1100, min(6000, T × 125 + 500))
x(t)  = 240 + (t - minTime) / span × (width - 490)
```

期間が1日より短い場合でも、最低1日幅に基づいて計算されます。すべてのイベントが同じ時刻の場合は、同じx座標に配置され、トラックに分割されます。

## 3。関連オブジェクト別の行とトラックを選択する [#3-관련-객체별-행과-트랙을-선택한다]

各イベントの`nodeIds`では、実際のグラフに存在する最初のオブジェクトを行として使用します。 1つのイベントが複数のオブジェクトを参照しても、1行だけにドロップします。オブジェクトが見つからない場合は、共通のイベント行を使用します。

行内では、開始日順に次の規則を適用します。

```text
track = 저장된 끝점 + 20px < 이번 사건의 x인 첫 트랙
        없으면 새 트랙
끝점  = max(x + 194px, 종료일의 x)
y     = 행 시작 + 24px + 트랙 번호 × 92px
행 높이 = max(110px, 트랙 수 × 92px + 34px)
```

たとえば、同じ視点の3つのイベントは異なるトラックに配置されます。期間バーが長い場合、イベントはそのバーが終わった後に同じトラックを書くことができます。まず、使えるトラックを選ぶ貪欲な配置です。

## 4。スケールを均等に分割する [#4-눈금을-균등하게-나눈다]

最小値と最大値が同じであれば、目盛は1個です。異なる場合は、次の数で2つの時刻の間を等分します。

```text
tickCount = min(7, max(2, ceil((maxTime - minTime) / 하루) + 1))
```

月の始まりや真夜中に合わせたカレンダースケールアルゴリズムではありません。日付表示はUTC日単位であるため、短い区間では目盛ラベルが重複する可能性があります。

## 複雑さと限界 [#복잡도와-한계]

整列は `O(T log T)` で、連続するトラック数が増加し続ける場合の最悪のトラック検索は `O(T²)` です。イベント内のオブジェクト参照の合計が`R`、オブジェクトの数が`V`、グループの数が`G`とすると、現在の線形探索を含む全体の上限は`O(T log T + T² + RV + T(V + G))`となります。結果として得られるストレージスペースは`O(T)`です。

時間軸は、グラフに指定されたイベントのみを示します。オブジェクト属性の日付を自動的にイベントに置き換えたり、不確実な日付を推定したりしません。大きなケースでは現在[ナビゲーション投影](/ja/docs/algorithms/exploration)に含まれている事件を配置します。

実装は [GraphRenderer.tsx の timelineLayout と dateLabel](https://github.com/d4d-cydf/Cluevia/blob/main/src/components/graph/GraphRenderer.tsx)、入力日付の検査は [graph-document.ts](https://github.com/d4d-cydf/Cluevia/blob/main/src/lib/graph-document.ts) を参照。
