`edgeGeometry` 接收一条关系、卡片坐标、是否处于 Lanes 视图及关系在数组中的序号，返回 SVG 路径和标签中心。任一端坐标缺失时，不生成该路径。

## 将边的两端连接到卡片边界 [#카드-경계에-양-끝을-연결한다]

设卡片中心的坐标差为 `(dx, dy)`，在卡片半宽和半高之外各留出 3px，计算连接位置。

```text
factor = min(94 / max(1, abs(dx)), 40 / max(1, abs(dy)))
A      = source + (dx, dy) × factor
B      = target - (dx, dy) × factor
```

卡片尺寸为 182×74px。普通关系从 A 与 B 的中点出发，沿 AB 的垂直方向偏移控制点 C，构造二次贝塞尔曲线。

```text
bend = 관계 순번 % 3이 0이면 16, 아니면 -16
C    = (A + B) / 2 + 수직 단위 벡터 × bend
P(t) = (1 - t)² A + 2(1 - t)t C + t² B
label = P(0.5) = (A + 2C + B) / 4
```

弯曲程度由关系在整个数组中的序号决定，而非同一对象对之间的关系数量。因此，同向的平行关系可能共用相同路径和标签位置。

## 同列关系与自环 [#같은-열과-자기-관계]

| 类型 | 路径和标签 |
| --- | --- |
| Lanes 中横向距离小于 1px | 根据序号奇偶，在卡片左侧或右侧 125px 处设置控制点，构造三次曲线。标签的 x 坐标取控制点的 x，y 坐标取两张卡片的中间值 |
| 指向自身的关系 | 卡片上方的三次曲线。端点相对中心为 x±34、y−37；控制点为 x±65、y−105 |
| 自环标签 | 相对卡片中心位于 y−83 |

同一对象的多个自环会发生重叠。路径计算完成后，按关系的 `source → target` 方向放置箭头。

## 标签规则 [#라벨-표시-규칙]

标签显示在 154×22px 的 SVG `foreignObject` 区域内。关系数少于 65 条时全部显示；达到或超过该数量时，仅显示已选关系及通过关键关系开关突出显示的关系标签。关系本身仍可选择，也保留 SVG 标题。

主张关系的状态 `reported` / `inferred` 反映在线型中。否认、撤回和不确定状态也可显示在标签上。这些显示方式不等于判定主张真实。

## 复杂性和局限性 [#복잡도와-한계]

若坐标 Map 的查询平均为常数时间，则单条关系的几何计算为 `O(1)`，整体为 `O(E)`。文本渲染成本另计。

当前实现不优化卡片与其他标签的遮挡面积，也不进行避交叉路径搜索。在密集图中，可通过拖动对象或[缩小探索范围](/zh/docs/algorithms/exploration)提高可读性。

实现见 [GraphRenderer.tsx 中的 edgeGeometry 与关系渲染](https://github.com/d4d-cydf/Cluevia/blob/main/src/components/graph/GraphRenderer.tsx)；界面验证见 [tests/graph.spec.ts](https://github.com/d4d-cydf/Cluevia/blob/main/tests/graph.spec.ts)。
