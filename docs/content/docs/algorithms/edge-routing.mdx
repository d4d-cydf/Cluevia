`edgeGeometry`는 관계 하나와 카드 좌표, Lanes 여부, 관계 배열 순번을 입력받아 SVG 경로와 라벨 중심을 반환합니다. 양 끝 좌표가 없으면 해당 경로를 만들지 않습니다.

## 카드 경계에 양 끝을 연결한다

카드 중심 차이를 `(dx, dy)`라 하면 카드 반폭·반높이에 3px을 더해 연결 위치를 구합니다.

```text
factor = min(94 / max(1, abs(dx)), 40 / max(1, abs(dy)))
A      = source + (dx, dy) × factor
B      = target - (dx, dy) × factor
```

카드 크기는 182×74px입니다. 일반 관계는 A와 B의 중앙에서 수직 방향으로 제어점 C를 옮겨 2차 베지어 곡선을 만듭니다.

```text
bend = 관계 순번 % 3이 0이면 16, 아니면 -16
C    = (A + B) / 2 + 수직 단위 벡터 × bend
P(t) = (1 - t)² A + 2(1 - t)t C + t² B
label = P(0.5) = (A + 2C + B) / 4
```

굽힘은 같은 객체 쌍의 개수 대신 전체 관계 배열의 순번으로 결정합니다. 따라서 같은 방향의 평행 관계가 같은 경로와 라벨 위치를 공유할 수 있습니다.

## 같은 열과 자기 관계

| 종류 | 경로와 라벨 |
| --- | --- |
| Lanes에서 가로 차이가 1px 미만 | 순번의 홀짝에 따라 카드 왼쪽·오른쪽으로 125px 떨어진 제어점을 쓰는 3차 곡선. 라벨은 제어점의 x와 두 카드의 중간 y |
| 자기 자신을 가리키는 관계 | 카드 위의 3차 곡선. 양 끝은 중심에서 x±34, y−37; 제어점은 x±65, y−105 |
| 자기 관계 라벨 | 카드 중심에서 y−83 |

같은 객체의 자기 관계가 여러 개면 같은 루프를 사용합니다. 경로 계산 후 화살표는 관계의 `source → target` 방향에 놓입니다.

## 라벨 표시 규칙

라벨은 154×22px의 SVG `foreignObject` 영역에 표시합니다. 관계가 65개 이하이면 모두 표시하고, 그보다 많으면 선택한 관계와 주요 관계 토글로 강조한 관계의 라벨만 표시합니다. 관계 자체는 선택할 수 있고 SVG 제목에도 이름을 제공합니다.

`reported`/`inferred`와 관계의 주장 태도는 선의 스타일에 반영됩니다. 부인·철회·불확실 상태는 라벨에도 표시할 수 있습니다. 표시 방식이 주장의 진실 여부를 판정하는 것은 아닙니다.

## 복잡도와 한계

좌표 Map 조회를 평균 상수 시간으로 보면 관계 하나의 기하 계산은 `O(1)`, 전체는 `O(E)`입니다. 텍스트 렌더링 비용은 별도입니다.

현재 구현은 카드·다른 라벨의 가림 면적을 최적화하거나 경로 교차를 피하는 탐색을 하지 않습니다. 빽빽한 그래프에서는 객체를 드래그하거나 [탐색 범위를 좁혀](/docs/algorithms/exploration) 근거를 읽습니다.
