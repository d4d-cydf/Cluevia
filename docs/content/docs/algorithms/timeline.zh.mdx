---
title: "时间轴布局"
description: "将事件的绝对时间映射到横坐标，并为重叠事件分配轨道。"
---

`timelineLayout` 按日期对图中的事件排序，并计算行、轨道、持续时间条和刻度。若 `events` 为空，则显示空时间轴，不推测日期。

## 1. 考虑时区后排序 [#1-시간대를-반영해-정렬한다]

使用 `Date.parse` 读取开始与结束日期，按开始时间升序排列；时间相同时，按 ID 的 `localeCompare` 结果排序。

```text
2017-08-12T01:30:00+09:00
→ 2017-08-11T16:30:00Z와 같은 좌표
```

时间轴及事件卡片的日期均按 UTC 日期显示。因此，它们可能与原文时区中的日期相差一天；同一天内不同时间的事件也可能显示相同日期标签。

## 2. 将时间映射到横坐标 [#2-시각을-가로-좌표로-투영한다]

取所有开始、结束时间的最小值和最大值。设事件数为 `T`，按下式计算：

```text
span  = max(86,400,000ms, maxTime - minTime)
width = max(1100, min(6000, T × 125 + 500))
x(t)  = 240 + (t - minTime) / span × (width - 490)
```

即使实际跨度不足一天，也至少按一天的时间跨度计算。所有事件发生于同一时刻时，它们具有相同的 x 坐标，但分配到不同轨道。

## 3. 按关联对象选择行与轨道 [#3-관련-객체별-행과-트랙을-선택한다]

对每个事件，取 `nodeIds` 中第一个实际存在于图中的对象作为所属行。即使事件引用多个对象，也仅选择一行；若找不到有效对象，则使用公共事件行。

在一行内，按照开始日期顺序应用下列规则:

```text
track = 저장된 끝점 + 20px < 이번 사건의 x인 첫 트랙
        없으면 새 트랙
끝점  = max(x + 194px, 종료일의 x)
y     = 행 시작 + 24px + 트랙 번호 × 92px
행 높이 = max(110px, 트랙 수 × 92px + 34px)
```

例如，同一时刻的三个事件会被放入不同轨道。持续时间条较长时，后续事件只有在该条结束后才能使用同一轨道。这是一种选择最早可用轨道的贪心布局。

## 4. 均匀划分刻度 [#4-눈금을-균등하게-나눈다]

最小值与最大值相同时，仅生成一个刻度；否则按下列数量等分两个时刻之间的区间。

```text
tickCount = min(7, max(2, ceil((maxTime - minTime) / 하루) + 1))
```

这不是将刻度对齐到月初或午夜的日历刻度算法。日期标签按 UTC 日期显示，因此在较短区间中，刻度标签可能重复。

## 复杂性和局限性 [#복잡도와-한계]

排序复杂度为 `O(T log T)`。同一行中的轨道数持续增加时，轨道搜索最坏为 `O(T²)`。设事件对对象的引用总数为 `R`、对象数为 `V`、组数为 `G`，则计入当前线性查找后的整体上界为 `O(T log T + T² + RV + T(V + G))`。结果存储空间为 `O(T)`。

时间轴仅显示图中明确给出的事件，不会自动将对象属性中的日期转换为事件，也不推测不确定日期。大规模图仅对当前[探索投影](/zh/docs/algorithms/exploration)中的事件进行布局。

实现见 [GraphRenderer.tsx 中的 timelineLayout 与 dateLabel](https://github.com/d4d-cydf/Cluevia/blob/main/src/components/graph/GraphRenderer.tsx)；输入日期检查见 [graph-document.ts](https://github.com/d4d-cydf/Cluevia/blob/main/src/lib/graph-document.ts)。
