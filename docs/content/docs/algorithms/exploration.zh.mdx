图探索从已存储数据中选择需要显示的部分。搜索、切换视图和缩放均不再次调用模型。案例对话中的原文搜索与图界面的搜索是两个独立功能。

## 为大图构建显示集合 [#큰-그래프의-표시-집합을-만든다]

只要对象数超过 200、关系数超过 1,000，或事件数超过 500，`GraphRenderer` 就显示由 `exploreGraph` 生成的子图。完整存储与导出仍保留原始全部条目。

### 以当前选择为起点扩展邻域 [#선택을-시작점으로-주변을-확장한다]

选择对象时，以该对象为起始集合；选择关系时，以两个端点对象为起点；选择事件时，以其关联对象为起点。连接范围为 1 或 2 时，每一步均遍历全部关系，并按以下规则扩展。

```text
A → B → C, 시작 집합 {A}
1단계: {A, B}
2단계: {A, B, C}
```

探索不区分关系方向，均可扩展到相邻对象。每步基于前一步集合的副本，因此一次遍历不会连续扩展多层。深度 0 表示完整列表。

### 应用搜索和类型条件 [#검색과-유형-조건을-적용한다]

搜索词与对象名称、类型、说明和属性值均经 NFKC 规范化及小写转换后比较。关系和事件的搜索字段如下。

| 项目 | 搜索字符串 |
| --- | --- |
| 关系 | 名称/描述 |
| 事件 | 名称/描述/开始日期 |

关系或事件匹配时，其关联对象也加入候选集合。目前关系与事件字符串仅作小写转换，因此其规范化方式与对象并不完全相同。

已选择的起始对象不受过滤条件影响。启用邻域探索后，邻居即使不直接匹配搜索词，也作为上下文保留；此时再应用对象类型过滤。

### 分页并限制关系数量 [#페이지를-만들고-관계를-제한한다]

默认对象显示上限为 200，函数参数接受 20–300。最多固定保留 20 个起始对象，再对剩余名额进行分页。

收集两个端点均在已选对象集合内的关系，优先排列已选关系和搜索匹配关系，最多显示 1,000 条。事件只要有一个关联对象属于显示集合，即可纳入，最多显示 500 个。界面提示隐藏的关系数，不删除原始数据。

## 在画布中突出显示匹配上下文 [#캔버스-안에서는-일치-맥락을-강조한다]

在小型图或投影后的图中，`GraphCanvas` 突出显示匹配搜索词的对象、匹配关系的两个端点，以及匹配事件中的对象；其余部分淡化显示。画布中的字符串比较基于小写转换，与投影函数中的 NFKC 处理不同。

若关系的两个端点都在匹配集合中，该关系也保持清晰显示。因此，界面匹配数可能包含这些上下文对象。关键关系开关使用输入的 `highlighted` 标记，不计算最短路径。

对象超过 100 个时，跳过视口周围预留边距以外卡片的 DOM 渲染；已选和正在拖动的卡片仍保留。关系边未采用相同方式整体虚拟化。

## 复用界面计算与布局状态 [#화면-계산과-배치-상태를-재사용한다]

| 手段 | 保留内容 |
| --- | --- |
| React `useMemo` | 图与视图等依赖不变时，复用布局、ID 映射和探索投影 |
| `priorScene` | 同一 Board 新增对象时保留已有坐标 |
| `localStorage` | 按图 ID 与视图保存手动拖动坐标 |

当前实现没有按图保存布局的全局 `WeakMap` 缓存。图变化时也会计算 Timeline 布局，因此不能假定只有打开 Timeline 时才发生这些计算。

初始缩放按场景宽度适配，并限制在 65–100%。Fit 同时按场景宽高适配，在视口内保留 28px 边距，范围为 2–100%。普通缩放范围为 2–180%。

## 服务器提取缓存和全文搜索 [#서버의-추출-캐시와-원문-검색]

[资料结构化](/zh/docs/algorithms/extraction)的七天缓存复用模型抽取结果。它与屏幕坐标缓存相互独立；本体、资料或处理设置变化时，缓存键也会变化。

案例对话使用已保存原文的倒排索引。搜索候选考虑韩语双字符片段、助词去除、标识符及有限同义词，再将相关原文传给模型。目前不使用语义嵌入搜索，也不会仅因同义词相同而合并对象。

## 费用和实施 [#비용과-구현]

围绕所选对象进行扩展时，深度为 `D`、关系数为 `E` 的复杂度为 `O(DE)`。搜索需扫描文本和引用；关系与事件候选的排序最坏为 `O(E log E + T log T)`。即使限制每页显示数量，候选搜索仍针对整个图进行。
