## 앱과 API 실행

Node.js 22.17 이상에서 루트 의존성을 설치한 뒤 빌드합니다.

```bash
npm ci --include=dev
npm run build
npm start
```

`server/index.ts`가 `dist/`의 화면과 제품 API를 함께 제공합니다. 기본 데이터 디렉터리는 `.cluevia/`이며 `CLUEVIA_DATA_DIR`로 바꿀 수 있습니다. 이 디렉터리는 재배포 후에도 보존하고, 같은 경로에 여러 서버를 동시에 실행하지 않습니다.

`npm run dev`와 `npm run preview`도 같은 제품 API·저장소를 사용합니다. `dist/`만 정적으로 배포하면 온톨로지 설계·분석 작업·서버 저장 기능은 실행되지 않습니다.

## 접속 설정

`npm start`의 호스트·포트는 `CLUEVIA_HOST`, `PORT`로 설정합니다. LAN 운영은 `CLUEVIA_HOST=0.0.0.0`과 `CLUEVIA_ACCESS_TOKEN`을 설정하고 웹 화면에서 연결키를 입력합니다. Vite 포트는 `npm run dev -- --port 5173 --strictPort`처럼 별도로 지정합니다.

접속 키가 없으면 API는 실제 loopback 연결만 허용합니다. 앱은 하나의 공유 워크스페이스이며 사용자별 데이터 분리나 역할별 권한은 제공하지 않습니다. 인터넷 운영에는 HTTPS와 인증된 접근 경로가 필요합니다.

새 분석에는 실행 계정의 Codex 로그인과 모델 접근이 필요합니다. Jev는 선택 사항입니다. 상세 변수와 동작 범위는 프로젝트 [README](https://github.com/d4d-cydf/Cluevia/blob/main/README.md)를 기준으로 설정합니다.

## 문서 정적 배포

```bash
npm run docs:install
npm run docs:build
```

`docs/out/`을 웹 루트로 배포합니다. 별도 Node 서버나 분석 API, 모델 자격증명은 필요하지 않습니다.

| 요청 | 제공할 파일 |
| --- | --- |
| `/` | `docs/out/index.html` |
| `/docs/.../` | 해당 폴더의 `index.html` |
| `/search-index.json` | 생성된 검색 인덱스 JSON |

모든 요청을 홈페이지로 보내는 SPA fallback 대신 디렉터리 인덱스를 제공합니다. 검색 JSON을 HTML로 덮어쓰면 검색이 동작하지 않습니다.

앱 링크는 빌드 환경 또는 `docs/.env.local`의 `NEXT_PUBLIC_CLUEVIA_URL`로 지정합니다. 기본값은 `http://127.0.0.1:5173`입니다. 공개 설정이므로 비밀 값을 넣지 않으며 주소를 바꾸면 다시 빌드합니다.

## 데이터 백업

서버를 종료한 뒤 데이터 디렉터리 전체를 백업합니다. 원문·DB·분석 기록을 함께 보존해야 하며 SQLite WAL 사용 중 DB 파일 하나만 복사하는 방식은 피합니다. 개별 그래프 내보내기와 통합 스냅샷의 포함 범위는 [저장과 가져오기](/docs/guide/import-export)에 있습니다.
