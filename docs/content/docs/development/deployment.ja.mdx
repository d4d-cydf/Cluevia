## アプリとAPIの実行 [#앱과-api-실행]

Node.js 22.17 以降でルート依存性をインストールしてビルドします。

```bash
npm ci --include=dev
npm run build
npm start
```

`server/index.ts`が`dist/`の画面と製品APIを一緒に提供します。デフォルトのデータディレクトリは`.cluevia/`で、`CLUEVIA_DATA_DIR`に置き換えることができます。このディレクトリは再配布後も保存され、同じパスに複数のサーバーを同時に実行しません。

`npm run dev`と`npm run preview`も同じ製品API・ストレージを使用します。 `dist/`のみ静的に配布すると、オントロジー設計・分析作業・サーバー保存機能は実行されません。

## 接続設定 [#접속-설정]

`npm start` のホストポートは、`CLUEVIA_HOST` と `PORT` に設定されます。 LAN操作の場合は、Web画面で`CLUEVIA_HOST=0.0.0.0`と`CLUEVIA_ACCESS_TOKEN`を設定し、接続キーを入力します。 Vite ポートは、`npm run dev -- --port 5173 --strictPort` として別途指定されます。

接続キーがない場合、APIは実際のループバック接続のみを許可します。アプリは1つの共有ワークスペースであり、ユーザー固有のデータの分離や役割固有の権限は提供しません。インターネット操作にはHTTPSと認証されたアクセスパスが必要です。

新しい分析には、実行アカウントのCodexログインとモデルアクセスが必要です。 Jevはオプションです。詳細変数と動作範囲はプロジェクト[README](https://github.com/d4d-cydf/Cluevia/blob/main/README.md)を基準に設定します。

## ドキュメント静的展開 [#문서-정적-배포]

```bash
npm run docs:install
npm run docs:build
```

`docs/out/`をWebルートとして配布します。個別のNodeサーバーや分析API、モデル認証情報は必要ありません。

| リクエスト | 提供するファイル |
| --- | --- |
| `/` | `docs/out/index.html` |
| `/docs/.../` | そのフォルダの`index.html` |
| `/search-index.json` | 生成された検索インデックスJSON |

すべての要求をホームページに送信するSPA fallbackの代わりにディレクトリインデックスを提供します。検索JSONをHTMLで上書きすると、検索は機能しません。

アプリリンクは、ビルド環境または`docs/.env.local`の`NEXT_PUBLIC_CLUEVIA_URL`として指定します。デフォルト値は`http://127.0.0.1:5173`です。公開設定なので、秘密の値を入れず、住所を変更すると再構築します。

## データのバックアップ [#데이터-백업]

サーバーをシャットダウンしてから、データディレクトリ全体をバックアップします。原文・DB・分析記録を一緒に保存する必要があり、SQLite WAL使用中にDBファイルを1つだけコピーする方法は避けてください。個々のグラフのエクスポートと統合スナップショットの包含範囲は、[保存とインポート](/ja/docs/guide/import-export)にあります。
