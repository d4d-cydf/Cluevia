앱은 Vite·Node API, 문서는 별도 Fumadocs·Next.js 패키지입니다. 앱 개발에는 Node.js **22.17 이상**을 사용합니다. 문서 패키지만 실행할 때의 최소 버전은 22.12입니다.

## 앱 설치와 실행

Windows PowerShell과 WSL 중 실행할 환경에서 설치합니다.

```bash
npm ci --include=dev --include=optional
npm run dev
```

앱 기본 주소는 `http://127.0.0.1:5173`입니다. 환경을 바꾸면 기존 서버를 종료하고 해당 환경에서 `npm ci`를 다시 실행합니다. 현재 앱에는 자동 재설치 predev 훅이 없습니다.

새 분석을 사용할 경우 같은 환경에서 `npm run codex:login`과 `npm run codex:status`를 실행합니다. 저장된 그래프와 공개 예제는 모델 연결 없이 열 수 있습니다. 환경 변수는 루트 `.env.example`과 [README](https://github.com/d4d-cydf/Cluevia/blob/main/README.md)를 참고하고, 기존 `.env.local`을 덮어쓰지 않습니다.

## 문서 실행

프로젝트 루트의 별도 터미널에서 실행합니다.

```bash
npm run docs:install
npm run docs:dev
```

문서 주소는 `http://127.0.0.1:3001`입니다. 본문은 `docs/content/docs/**/*.mdx`, 사이드바 순서는 각 `meta.json`, 랜딩은 `docs/components/home.tsx`에서 편집합니다.

문서 실행·빌드·타입 검사는 필요한 실행 파일과 현재 운영체제의 네이티브 모듈을 먼저 확인합니다. 미설치나 Windows/WSL 전환을 감지하면 docs 의존성을 다시 설치합니다. 정상 상태에서는 재설치하지 않습니다.

```bash
npm run docs:typecheck
npm run docs:build
npm run test:docs
```

`docs:build`는 `docs/out/`에 정적 사이트를 만듭니다. 모델 로그인이나 API 키 없이 실행합니다. `NEXT_PUBLIC_CLUEVIA_URL`은 문서의 앱 링크이며 빌드 시 반영되는 공개 설정입니다.

## 앱 빌드와 서버

```bash
npm run build
npm start
```

빌드는 TypeScript 검사 후 `dist/`를 생성합니다. `npm start`가 빌드된 화면과 API를 함께 제공합니다. `npm run preview`는 Vite 미리보기와 같은 제품 API를 실행합니다. 같은 데이터 디렉터리를 여러 서버에서 동시에 열지 않습니다.

## 테스트

```bash
npm test
npx playwright install chromium
npm run test:e2e
```

단위·HTTP 테스트는 계약, 원문 근거, 저장, 작업·취소·재개와 API를 검사합니다. 실제 모델 호출이 필요한 별도 평가 명령은 일반 테스트와 구분합니다.

| 환경 변수 | 용도 |
| --- | --- |
| `PLAYWRIGHT_BASE_URL` | 앱 브라우저 테스트에 기존 서버 사용 |
| `DOCS_BASE_URL` | 문서 테스트에 기존 서버 사용. 정적 `docs/out/` 서버도 가능 |
| `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` | 테스트용 Chromium 실행 파일 지정 |

`test:docs`는 루트에 설치된 Playwright와 `docs/playwright.config.ts`를 사용합니다. 기본적으로 문서 개발 서버를 시작하고, 검색·문서 경로·예제·모바일·테마를 확인합니다.

알고리즘 문서를 바꿀 때는 상수·분기 조건·구현 링크를 현재 코드와 맞추세요. 테스트가 확인한 사례를 모든 입력의 보장으로 확대하지 않습니다.
