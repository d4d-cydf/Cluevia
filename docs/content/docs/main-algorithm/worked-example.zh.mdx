在本节中，我们追踪候选组的变化，理由证据缺口和支持分数，通过一个配置示例来验证订单的交付。 为了澄清阶段之间的差异，数据的内容和充分性判断明确确定。 下面的数据，分数和阈值 都是解释目的的假设，而不是实验结果，表明实际分析准确性或操作默认值。

## 目标和逻辑 [#목표와-논리]

目标H是2026年10月05日交付O-17订单到W仓库。

```text
H [AND]
├─ C1: 해당 인도 행위가 발생했다 [OR]
│  ├─ E1: 입고 로그
│  ├─ E1-copy: 같은 로그의 재게시 자료
│  ├─ E2: 독립 수령 확인 기록 — 나중에 확보
│  └─ E4: 다른 주문의 수령 기록
└─ C2: 그 인도 기록이 O-17과 연결된다 [OR]
   └─ E3: 주문–입고 번호 대조표 — 처음에는 없음
```

C1 资料还须带有可与 O-17 关联的入库键、时间与地点。C2 验证该入库键与订单 O-17 的直接关联。若二者来自同一文档，仍须单独核查独立性。本例中，1-4 检查各记录是否支持实际交付完成；1-5 检查所选记录与对照表的事件键是否连接。

## 初始数据和评估假设 [#초기-자료와-평가-가정]

| 材料 | 内容 | 数据判断 | 事件/来源 |
| --- | --- | --- | --- |
| E1 | 10-05，仓库 W，入库 R-17 已完成 | 对 C1 为 `SUPPORTED` | 原始日志，示例 p=0.90 |
| E1-copy | 原样转发 E1 的记录 | 对 C1 为 `SUPPORTED` | 同一观测，非独立资料 |
| E4 | 入库 R-71，订单 O-71 | 支持一般交付条件 | 不符合目标关联规则 |
| E5 | 10-05 预计交付 O-17 | 对 C1 为 `INSUFFICIENT` | 计划不能证明实际完成 |
| E6 | 无来源的完成声明截图 | 内容支持主张 | E 级，谱系未核实 |

E5 与 E6 同样保留在原始资料中。将其关联到树的证据要求后，在适合性或来源阶段诊断；上方简化图省略了这些节点。

## 执行 A · C2 没有数据 [#실행-a--c2-자료가-없음]

1-3 中即使已有 C1 候选资料，由于 C2 的 `F(C2)=∅`，根候选集合仍为空。

<Equation number="W1" label={"没有要求连接的候选人"} tex={String.raw`F(C_2)=\varnothing\quad\Longrightarrow\quad F(H)=\varnothing`} />

结果为 C2 的 `EVIDENCE_MISSING`，以及以其为原因为根节点记录的 `CHAIN_UNKNOWN`。不继续计算后续可信度，也不将分数设为 0 后宣称主张为假。

搜索同时列出 O-17 与 R-17 的原始对照表。若它属于非公开内部记录，则说明所需字段并请求用户提供。`CHAIN_UNKNOWN` 给出原始签收凭证、日志交叉核查及独立验证三种策略。

## 运行 B · 加入 E3，检查现有替代路径 [#실행-b--e3-추가-기존-대안-검사]

假定 E3 明确记载 O-17↔R-17、地点 W 和日期 10-05，并已通过支持性、事件一致性及来源检查。示例设定 p(E3)=0.80。

| 步骤 | 变化 |
| --- | --- |
| 1-3 | 将每个 C1 替代候选与 E3 组合 |
| 1-4 | E5 仅为计划，排除并记录 `EVIDENCE_INSUFFICIENT` |
| 1-5 | E4 的 O-71/R-71 与 E3 的 O-17/R-17 不匹配，记录 `EVENT_MISMATCH` |
| 1-6 | E1 与 E1-copy 归为同一观测，以单个 atom a 表示 |
| 1-7 | E6 为 E 级，记录 `PROVENANCE_UNKNOWN`；该替代路径不合格 |
| 1-8 | 计算合格候选 AND(a,b) 的分数，其中 b 为 E3 |

在**示例假设**中，E1 与 E3 相互独立，因此得到下式。

<Equation number="W2" label={"运行 B——关联已完整，但支持不足"} tex={String.raw`s_B(H)=0.90\cdot0.80=0.72<\tau_{\mathrm{example}}=0.80`} />

结果为 `COMPLETE_CHAIN_FOUND` 与 `TRUST_WEAK`：链已经完整，但分数不足。E4、E5、E6 的 gap 保留为已排除替代路径的问题。由于并非所有路径都已消失，不新增 `CHAIN_UNKNOWN`。

若误将 E1-copy 作为独立资料，C1 会被算为 0.99，H 为 0.792。重复资料增加文件数量，却不应使正确分数从 0.72 上升。

## 运行C · 添加独立收据记录 E2  [#실행-c--독립-수령-기록-e2-추가]

假设 E2 已确认为独立观测，且 p(E2)=0.75。E1 与 E2 分别可以单独支持 C1，但两条路径都需要 E3 提供订单关联。

候选人是 `{a,b}` ,  `{c,b}` 而逻辑表达式是 `(a OR c) AND b` .

<Equation number="W3" label={"运行 C——增加新观测后仍然存在的关联瓶颈"} tex={String.raw`\begin{aligned}s(C_1)&=1-(1-0.90)(1-0.75)=0.975\\s_C(H)&=0.975\cdot0.80=0.78\end{aligned}`} />

<ResearchDiagram kind="bottleneck" number="W2" />

资料增加后，结果仍低于 0.80。迷你图展示 C2 这一共享瓶颈。两个候选共享 b，因此不能再次以独立 OR 对候选分数求合。

此阶段的 Gap Fill 应请求能够核实 O-17↔R-17 原始关联的资料，而非继续添加与 C1 内容相同的文章。

## 运行 D · 核查 E3 原始谱系并重新评估 [#실행-d--e3-원본-계보-확인과-재평가]

假设 E3 的原始记录与发布路径已核实，对应 binding 的分数重新评估为 0.95。该变化须附有核查资料、评分依据及新策略或评估版本，不能仅为跨过目标阈值而提高分数。

<Equation number="W4" label={"运行 D——核实原始来源后重新评估"} tex={String.raw`s_D(H)=0.975\cdot0.95=0.92625\ge\tau_{\mathrm{example}}`} />

在独立性假设和资料判定均保持有效的新运行中，结果达到示例阈值。之前的分数与 TRUST_WEAK 记录应作为历史保留，并与最新运行的解除状态关联。UI 应表述为“满足示例分数模型中的标准”，不能在未经统计验证时写成“结论为真的概率为 92.625%”。

## 应用于否定主张 [#부정-주장에-대한-적용]

主张 N 为“截止前未取消”。必须具备核查时段、记录完整性、对象一致性及直接支持否定命题的依据。若支持该否定命题的两个条件相互独立，分数分别为 0.9 和 0.8，则 AND 的结果为 0.72。

任何一个必要条件缺失时，应在 1-3 记录缺口，不能将结果变为 0.28 或 1.0。仅仅未找到取消记录，不表示 N 已获证明。

## 应用于来源谱系追踪 [#출처-계보-추적에-대한-적용]

| 路径 | 审判 | 处理 |
| --- | --- | --- |
| 复制页面 → 已获取相同的日志 | 没有新信息 | 保存现有数据，没有重复添加 |
| 文章 → 原始记录 → 原始由出版社存档 | 逐步检查原始文本和引用 | 当符合1.0系数类型的确认条件时结束。 |
| A → B → A | 循环 | `CYCLE_DETECTED`，保留访问列表 |
| 文章 → 无法访问的原文 | 尚未核实 | 不将 LR 任意设为 1；D/E 时记录 `PROVENANCE_UNKNOWN` |

本例的要点是：缺口是否消除，取决于**相应必要关联得到满足并通过重新验证**，而不是资料数量是否增加。
