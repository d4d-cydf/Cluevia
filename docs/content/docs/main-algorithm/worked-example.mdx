이 절에서는 주문의 인도 완료를 검증하는 구성 사례를 통해 후보 집합, 공백 사유와 지지 점수의 변화를 추적한다. 단계 간 차이를 분명히 하기 위해 자료의 내용과 적합성 판정을 명시적으로 설정한다. 아래 자료·점수·임계값은 모두 설명을 위한 가정이며, 실제 분석의 정확도나 운영 기본값을 제시하는 실험 결과가 아니다.

## 목표와 논리

목표 H는 “2026-10-05에 주문 O-17이 창고 W에 인도되었다”다.

```text
H [AND]
├─ C1: 해당 인도 행위가 발생했다 [OR]
│  ├─ E1: 입고 로그
│  ├─ E1-copy: 같은 로그의 재게시 자료
│  ├─ E2: 독립 수령 확인 기록 — 나중에 확보
│  └─ E4: 다른 주문의 수령 기록
└─ C2: 그 인도 기록이 O-17과 연결된다 [OR]
   └─ E3: 주문–입고 번호 대조표 — 처음에는 없음
```

C1의 자료도 O-17과 연결할 수 있는 입고 키와 기간·장소를 가져야 한다. C2는 그 입고 키와 주문 O-17의 직접 연결을 확인한다. 서로 같은 문서에서 추출되었으면 이후 독립성도 별도로 검사해야 한다. 이 예제의 1-4는 각 기록이 인도 완료라는 행위 내용을 지지하는지 확인하고, 1-5는 선택한 기록과 대조표의 사건 키가 함께 연결되는지 검사한다.

## 초기 자료와 평가 가정

| 자료 | 내용 | 자료 판정 | 사건·출처 |
| --- | --- | --- | --- |
| E1 | 10-05 창고 W, 입고 R-17 완료 | C1에 `SUPPORTED` | 원본 로그, 예제 p=0.90 |
| E1-copy | E1 로그를 그대로 재게시 | C1에 `SUPPORTED` | 같은 관측이며 독립 자료 아님 |
| E4 | 입고 R-71, 주문 O-71 수령 | 인도 행위라는 일반 조건에는 지지 | 목표 연결 규칙과 불일치 |
| E5 | O-17을 10-05 배송할 예정 | C1에 `INSUFFICIENT` | 예정은 실제 완료를 입증하지 못함 |
| E6 | 출처 없는 완료 주장 캡처 | 내용상 지지를 주장 | 등급 E, 계보 미확인 |

E5와 E6도 원본 자료에는 남는다. 트리의 증거 요구에 연결되면 판정·출처 단계에서 진단하며, 위 간략도에서는 생략했다.

## 실행 A · C2 자료가 없음

1-3에서 C1 후보 자료가 있어도 C2의 `F(C2)=∅`이므로 루트 후보는 공집합이다.

<Equation number="W1" label="필수 연결이 없을 때의 후보" tex={String.raw`F(C_2)=\varnothing\quad\Longrightarrow\quad F(H)=\varnothing`} />

결과는 C2의 `EVIDENCE_MISSING`과 이를 원인으로 하는 루트 `CHAIN_UNKNOWN`이다. 후속 신뢰도는 계산하지 않는다. 점수를 0으로 만들어 “거짓”이라고 말하지 않는다.

Gap Fill은 O-17과 R-17이 함께 표시된 원본 대조표·수령증을 검색한다. 공개되지 않은 내부 기록이라면 어떤 필드를 포함해야 하는지 설명하고 사용자에게 요청한다. `CHAIN_UNKNOWN`에는 원본 수령증 경로, 로그 교차 경로, 독립 확인 경로의 세 전략을 제시한다.

## 실행 B · E3 추가, 기존 대안 검사

E3에 O-17↔R-17, 장소 W, 날짜 10-05가 명시되었고 지지·사건·출처 검사를 통과했다고 가정한다. 예제 p(E3)=0.80이다.

| 단계 | 변화 |
| --- | --- |
| 1-3 | C1 대안마다 E3을 결합한 후보 생성 |
| 1-4 | E5는 예정만 있으므로 `EVIDENCE_INSUFFICIENT`로 탈락 |
| 1-5 | E4의 O-71/R-71은 E3의 O-17/R-17과 맞지 않아 `EVENT_MISMATCH` |
| 1-6 | E1과 E1-copy는 같은 관측으로 묶고 한 atom a로 사용 |
| 1-7 | E6은 등급 E이므로 `PROVENANCE_UNKNOWN`; 해당 대안 부적격 |
| 1-8 | 적격 후보 a AND b(E3)의 점수 계산 |

E1과 E3의 불확실성이 독립이라는 **예제 가정** 아래 다음을 얻는다.

<Equation number="W2" label="실행 B — 연결은 완성되지만 지지가 부족함" tex={String.raw`s_B(H)=0.90\cdot0.80=0.72<\tau_{\mathrm{example}}=0.80`} />

결과는 `COMPLETE_CHAIN_FOUND`와 `TRUST_WEAK`다. 체인은 완성되었으나 점수가 충분하지 않다. E4·E5·E6의 gap은 탈락한 대안의 문제로 남으며, 모든 경로가 사라진 것이 아니므로 새 `CHAIN_UNKNOWN`을 붙이지 않는다.

E1-copy를 독립 자료로 잘못 계산하면 C1=0.99, H=0.792가 된다. 중복이 자료 수를 늘려도 신뢰도는 0.72에서 증가하면 안 된다.

## 실행 C · 독립 수령 기록 E2 추가

E2는 독립 관측으로 확인되었고 p(E2)=0.75라고 가정한다. E1과 E2는 각각 단독으로 C1을 지지하는 대안이며, 둘 다 E3의 주문 연결을 필요로 한다.

후보는 `{a,b}`, `{c,b}`이며 논리식은 `(a OR c) AND b`다.

<Equation number="W3" label="실행 C — 새 관측 이후에도 남는 연결 병목" tex={String.raw`\begin{aligned}s(C_1)&=1-(1-0.90)(1-0.75)=0.975\\s_C(H)&=0.975\cdot0.80=0.78\end{aligned}`} />

<ResearchDiagram kind="bottleneck" number="W2" />

자료가 늘었지만 여전히 0.80보다 낮다. 미니 그래프는 C2의 공유 병목을 보여준다. 두 후보가 b를 공유하므로 후보별 점수를 다시 독립 OR로 합산해서는 안 된다.

이 단계의 Gap Fill은 C1과 같은 내용의 기사 추가보다 O-17↔R-17의 원본 연결을 확인할 자료를 요구한다.

## 실행 D · E3 원본 계보 확인과 재평가

E3의 원본 기록과 발행 경로가 확인되어 해당 binding의 신뢰도를 0.95로 재평가했다고 가정한다. 값 변경에는 확인 자료·평가 근거와 새 정책 또는 평가 버전을 남긴다. 단순히 목표 임계값을 넘기기 위해 수치를 높이는 것이 아니다.

<Equation number="W4" label="실행 D — 원출처 확인에 따른 재평가" tex={String.raw`s_D(H)=0.975\cdot0.95=0.92625\ge\tau_{\mathrm{example}}`} />

독립성 가정과 자료 판정도 유지되는 새 실행에서 예제 임계값을 충족한다. 이전 점수와 TRUST_WEAK 기록은 이력으로 남기고 최신 실행에서 해소 상태를 연결한다. UI 설명은 “예제 점수 모형에서 기준 충족”이며 통계 검증 없이 “진실 확률 92.625%”라고 쓰지 않는다.

## 부정 주장에 대한 적용

주장 N은 “마감 전 취소되지 않았다”다. 확인 구간·기록 완전성·대상 일치와 직접적인 부정 근거가 있어야 한다. 부정 주장을 지지하는 두 조건의 독립 점수가 0.9와 0.8이면 AND 결과는 0.72다.

둘 중 하나가 없으면 1-3의 공백이며, 0.28 또는 1.0으로 바꾸지 않는다. 현재 취소 자료를 못 찾은 것만으로 N이 입증된 것은 아니다.

## 출처 계보 추적에 대한 적용

| 경로 | 판정 | 처리 |
| --- | --- | --- |
| 재게시 페이지 → 이미 확보한 같은 로그 | 새 정보 없음 | 기존 자료 유지, 중복 가산 없음 |
| 기사 → 원본 기록 → 발행기관 보관 원본 | 단계별 원문·인용 확인 | 계수 1.0 타입의 확인 조건을 충족하면 종료 |
| A → B → A | 순환 | `CYCLE_DETECTED`, 방문 목록 보존 |
| 기사 → 접근 불가 원문 | 미확인 | LR을 임의로 1로 만들지 않음; D/E면 `PROVENANCE_UNKNOWN` |

이 예제의 핵심은 공백 해소가 “자료 개수 증가”가 아니라 **해당 필수 연결의 충족과 재검증**으로 결정된다는 점이다.
