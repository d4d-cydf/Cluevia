製品APIは`server/product-api.ts`にあり、開発サーバー・プレビューと`npm start`に接続されています。すべてのパスは、アプリと同じホストの`/api/`の下にあります。

## 接続と認証 [#연결과-인증]

`GET /api/system/status`で接続・エンジン・貯蔵所の状態を確認します。ワークスペースキーが設定されている場合は、要求に`Authorization: Bearer <워크스페이스 키>`を使用します。キーがない場合、実際のループバック接続のみがAPIを使用できます。

現在のアプリは共有ワークスペースです。ユーザー別アカウント・権限・資料分離APIは提供しません。

## 分析の確認とデータのアップロード [#분석-확인과-자료-업로드]

| リクエスト | アクション |
| --- | --- |
| `POST /api/analysis/clarify` | 質問・資料のプレビュー・前回答で確認 質問または分析範囲返却。ファイルアップロード・ジョブ生成なし |
| `POST /api/documents/upload` | 生ファイル本文をアップロード→`201 {document}` |
| `GET /api/documents/:id` | アップロードした資料のサイズ・区間情報 |

アップロードは`Content-Type: application/octet-stream`と`X-File-Name: encodeURIComponent(name)`を使用します。資料はUTF-8テキストでなければなりません。デフォルトのファイルサイズ上限はなく、`CLUEVIA_MAX_UPLOAD_MB`に制限できます。

## ジョブの作成と照会 [#작업-생성과-조회]

```json
{
  "question": "자료에 등장하는 객체와 관계를 정리해줘",
  "documents": [],
  "uploadIds": ["upload-업로드응답의ID"]
}
```

上記のリクエスト構造では、アップロードIDは実際のアップロード応答値に置き換えられます。小さなインラインデータは`documents: [{id,name,text,url?}]`に渡すことができます。選択的`analysisBrief`に確定した目的・範囲・結果・答弁をお届けします。

| リクエスト | アクション |
| --- | --- |
| `POST /api/jobs` | ジョブ登録→`202 {job}` |
| `GET /api/jobs`, `GET /api/jobs/:id` | タスクリストとステータス |
| `POST /api/jobs/:id/cancel` | 進行中の分析のキャンセル、保存した結果の維持 |
| `POST /api/jobs/:id/resume` | 未完了区間の再開 |
| `DELETE /api/jobs/:id` | ケースと関連履歴の削除 |

インライン文書はそれぞれ50,000文字、合計150,000文字以下です。インラインとアップロード資料を合わせて最大10個です。実行・待機ジョブの合計は最大5個で、全体のジョブは順次実行します。

## 統合ケースと根拠 [#통합-케이스와-근거]

| リクエスト | アクション |
| --- | --- |
| `GET /api/jobs/:id/case` | 統合グラフ、履歴リスト、基礎リンクと属性の違い |
| `GET /api/jobs/:id/records/:number` | 当該記録のグラフ・根拠・原文第1ページ |
| `GET /api/jobs/:id/records/:number/document?id=...&offset=...` | 記録に属する原稿ページ |
| `GET /api/jobs/:id/decisions` | 資料別Jev判定履歴 |
| `GET /api/jobs/:id/chat`, `POST /api/jobs/:id/chat` | ケース会話照会・質問 |
| `POST /api/jobs/:id/claims/:edgeId/review` | 関係主張にレビューステータスとメモを保存 |

原文ページは12,000文字ずつ提供します。原文オフセットと引用位置の単位はUTF-16です。会話POSTには、`question`とオプションの`selection: {kind,id}`を渡します。

## グラフとオントロジー [#그래프와-온톨로지]

| リクエスト | アクション |
| --- | --- |
| `GET /api/graphs`, `GET /api/graphs/:id` | 保存グラフ一覧・内容 |
| `GET /api/graphs/:id/collection` | 同じタスクの部分グラフのリスト |
| `POST /api/graphs/import` | `{graph}` 完成 JSON検証・保存 |
| `DELETE /api/graphs/:id` | 独立グラフの削除。分析に属するグラフはケース削除を使用 |
| `GET /api/ontology` | オントロジー リスト・統計 |
| `GET /api/ontology/definitions/:id` | 定義・バージョン・タイプ・属性・関係・処理政策 |
| `GET /api/ontology/entities?q=&type=&ontologyId=` | オブジェクト検索 |
| `GET /api/ontology/entities/:id` | オブジェクトの主張・関係・根拠 |
| `POST /api/ontology/entities/:id/identity` | 他のオブジェクトとの同一性レビューの保存 |

## エラー応答 [#오류-응답]

無効な入力は400、認証失敗は401、他のサイトの要求制限は403、ないリソースは404として処理されます。分析所属グラフの単独削除は409、アップロード容量制限は413、サポートしないアップロード Content-Typeは415、キュー・同時リクエスト限度は429を使用できます。

ジョブが登録された後に発生した分析エラーは、ジョブ状態でも確認する必要があります。 HTTP ジョブ登録の成功は、完全な分析の成功を意味しません。
