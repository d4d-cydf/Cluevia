title: "GraphDocument"

---

`GraphDocument`は、公開例、インポートされたJSON、単一の分析結果が共有するグラフ表示契約です。タイプ定義は`src/types/graph.ts`、実行時検証は`src/lib/graph-document.ts`にあります。

## 有効な最小例 [#유효한-최소-예제]

以下の内容をUTF-8JSONファイルとして保存して**グラフJSONインポート**で開くことができます。例を説明するための仮想的な資料であり、関係と日付ある出来事はない状態です。

```json title="minimal.graph.json"
{
  "schemaVersion": "1.0",
  "id": "research-note",
  "title": "프로젝트 자료 정리",
  "question": "자료에 등장하는 프로젝트는 무엇인가?",
  "summary": "프로젝트 소개 메모에 등장하는 대상을 정리했습니다.",
  "origin": "imported",
  "createdAt": "2026-10-01T09:00:00+09:00",
  "limitations": ["형식 설명용 가상 자료입니다."],
  "groups": [
    { "id": "projects", "label": "프로젝트", "color": "#B8321A" }
  ],
  "sources": [
    {
      "id": "note-1",
      "title": "프로젝트 소개 메모",
      "excerpt": "Cluevia는 자료의 객체와 관계를 살펴보는 프로젝트입니다."
    }
  ],
  "nodes": [
    {
      "id": "cluevia",
      "label": "Cluevia",
      "type": "project",
      "group": "projects",
      "description": "메모에 소개된 프로젝트",
      "sourceIds": ["note-1"],
      "properties": {}
    }
  ],
  "edges": [],
  "events": [],
  "findings": []
}
```

## トップレベルフィールド [#최상위-필드]

以下のフィールドはすべて必要です。空の配列にもフィールド自体を含めてください。

| フィールド | タイプ/制限 | 意味 |
| --- | --- | --- |
| `schemaVersion` | `"1.0"` | 現在サポートされているスキーマバージョン |
| `id` | ID、最大80文字 | グラフID。コロン使用不可 |
| `title` | 文字列、1–200文字 | ケースタイトル |
| `question` | 文字列、1–2,000 文字 | 分析上の問い |
| `summary` | 文字列、1–5,000 文字 | 要約 |
| `origin` | `published-source`, `imported`, `aip`, `codex`, `jev`, `structured`, `demo` | 作成パス |
| `createdAt` | ISOの日付または時刻 | 文書作成時点 |
| `limitations` | 文字列配列、0–20個 | 各1–1,000文字の解釈限界 |
| `groups` | `GraphGroup[]`、1–12個 | オブジェクト分類 |
| `sources` | `GraphSource[]`、1–30個 | 根拠資料 |
| `nodes` | `GraphNode[]`、1–200個 | オブジェクト |
| `edges` | `GraphEdge[]`、0–500個 | 関係 |
| `events` | `GraphEvent[]`、0–300個 | 日付付きイベント |
| `findings` | `GraphFinding[]`、0–30個 | 分析文 |

選択フィールド`ontologyId`と`ontologyVersion`は一緒に使用します。 IDは一般的なID規則に従い、バージョンは1以上の安全定数です。上記の数の制限は単一のグラフに適用され、複数のレコードを組み合わせたサーバーケースの投影は別々です。

## グループ・GraphGroup [#그룹--graphgroup]

| フィールド | 必須 | ルール |
| --- | --- | --- |
| `id` | はい | ID |
| `label` | はい | 1–100文字 |
| `color` | はい | 正確に6桁の16進数`#RRGGBB` |

## 出典 · GraphSource [#출처--graphsource]

| フィールド | 必須 | ルール |
| --- | --- | --- |
| `id` | はい | ID |
| `title` | はい | 1–300文字 |
| `url` | いいえ | 最大 2,048文字のHTTPまたはHTTPS URL、ユーザー名・パスワード含む不可 |
| `publisher` | いいえ | 1–150文字 |
| `publishedAt` | いいえ | ISOの日付または時刻 |
| `accessedAt` | いいえ | ISOの日付または時刻 |
| `excerpt` | いいえ | 1–1,200 文字 |
| `contentHash`, `sourceFamily` | いいえ | 小文字の16進数64桁のハッシュ |

出典はURLなしでタイトルとIDだけで有効です。 URL は `URL` パーサーで正規化され、ブラウザが 出典 を表示するときに原稿の移動に使用します。 URL コンテンツ自動収集機能はありません。

## オブジェクト · GraphNode [#객체--graphnode]

| フィールド | 必須 | ルール |
| --- | --- | --- |
| `id` | はい | ID |
| `label` | はい | 1–180文字 |
| `type` | はい | 1–80文字。事前に固定されたタイプのリストはありません |
| `group` | はい | 存在するグループID |
| `description` | はい | 0–2,000文字。空の文字列を許可 |
| `sourceIds` | はい | 出典参照、最低1個 |
| `properties` | はい | 文字列値のオブジェクト、最大25個の属性。空のオブジェクトを許可 |

`properties`のキーは1–100文字、値は0–500文字の文字列とする。インポートするJSONでは数値と真偽値も文字列として記述する。キーと値の先頭および末尾の空白は除去する。

## 関係 · GraphEdge [#관계--graphedge]

| フィールド | 必須 | ルール |
| --- | --- | --- |
| `id` | はい | ID |
| `source` | はい | 開始オブジェクトID |
| `target` | はい | エンドオブジェクトID |
| `label` | はい | 1–150文字 |
| `description` | はい | 0–2,000文字 |
| `status` | はい | `reported`または`inferred` |
| `sourceIds` | はい | 出典参照、最低1個 |
| `highlighted` | いいえ | ブーリアン。主な関係を強調するかどうか |
| `claim` | いいえ | 資料に表現された主張態度・主体・期間・再引用 |

`source`と`target`の両方が存在しなければなりません。同じオブジェクトを指す関係と同じオブジェクトのペアの複数の関係も許可します。各関係の`id`は異なります。

### 関係主張・RelationClaim [#관계-주장--relationclaim]

`claim`を使用すると、以下のすべてのキーが含まれます。 `stance`以外の値は分からない場合は`null`のままにしてください。

| フィールド | 値 |
| --- | --- |
| `stance` | `asserted`, `denied`, `retracted`, `uncertain` |
| `attributedTo`, `derivedFrom` | 主張 主体・再引用 出典、各1–500文字文字列または`null` |
| `validFrom`, `validTo`, `publishedAt` | 実際のISO日付・時刻または`null` |

有効期間が逆転した場合は拒否します。ユーザーレビュー状態の`review`はサーバーケースで付け加える情報であり、この共通JSONパーサーが保存するフィールドではありません。

## イベント・GraphEvent [#사건--graphevent]

| フィールド | 必須 | ルール |
| --- | --- | --- |
| `id` | はい | ID |
| `label` | はい | 1–180文字 |
| `date` | はい | ISOの日付または時刻 |
| `endDate` | いいえ | 開始日以降のISO日付または時刻 |
| `description` | はい | 0–2,000文字 |
| `nodeIds` | はい | オブジェクト参照、少なくとも1つ |
| `sourceIds` | はい | 出典参照、最低1個 |

## 分析 · GraphFinding [#분석--graphfinding]

| フィールド | 必須 | ルール |
| --- | --- | --- |
| `text` | はい | 1–2,000文字 |
| `sourceIds` | はい | 出典参照、最低1個 |
| `nodeIds` | はい | オブジェクト参照、空の配列を許可する |
| `edgeIds` | いいえ | 関係参照、空の配列を許可する |

分析項目には別の`id`はありません。 `nodeIds: []`でも根拠である`sourceIds`は必要です。

## 共通検証ルール [#공통-검증-규칙]

### IDと参照 [#id와-참조]

IDは最大80文字で、英字・数字で始まります。以降は英文・数字・点・下線・コロン・ハイフンのみ許可します。最上位グラフ `id` のみコロンは使用できません。

```text
일반 ID: /^[a-zA-Z0-9][a-zA-Z0-9._:-]*$/
그래프 ID: /^[a-zA-Z0-9][a-zA-Z0-9._-]*$/
```

各`groups`、`sources`、`nodes`、`edges`、`events`配列内でIDは重複できません。異なる種類の配列間でグローバルな重複チェックは行われません。

参照配列はそれぞれ最大200個で、同じIDを2回入れることはできません。 出典参照は`sources`、オブジェクト参照は`nodes`、関係参照は`edges`、オブジェクトのグループ参照は`groups`に存在する必要があります。

### 文字列と選択フィールド [#문자열과-선택-필드]

文字列は長さを検査してから前後の空白を除去する。空の値を認めないフィールドでは、空白だけの文字列も拒否する。表の文字数はJavaScript文字列の`length`を基準とし、UTF-8のバイト数とは異なる。

選択フィールドを使用しない場合は省略してください。 「一般選択」フィールドでは、`null`は省略に代わるものではありません。 `claim`内部のnullable値は上記の契約に従います。不明な追加フィールドは、検証された結果から削除されます。

### 日付 [#날짜]

日付のみを記録するか、秒と時間帯までのISO時刻を使用します。時刻の小数秒は1–3桁まで許可します。

```text
2026-10-01
2026-10-01T09:30:00+09:00
2026-10-01T00:30:00.123Z
```

存在しないカレンダーの日付、タイムゾーンが欠落した時刻、開始よりも前の終了日は拒否されます。

## ファイルサイズとエラー [#파일-크기와-오류]

`parseGraphText`とファイルインポートのサイズ制限は**2,000,000バイト**です。 UTF-8サイズに基づいており、`parseGraphDocument`のオブジェクトチェックとは別です。ブラウザの保存方法も保存するJSONのサイズを確認します。

検証は最初のエラーで中止されます。 `node.label`、`edge 관계ID`、`events[0]`のように、検査の場所と種類によってパスが異なり、すべてのエラーに配列順番とIDが一緒に表示されるわけではありません。

<Callout title={"インポートから変更される値"}>
ファイルの元のフィールドと参照を最初に検証し、`origin`を`imported`に置き換えて、保存時に新しいグラフIDを付与します。サーバーのインポートは、`ontologyId`・`ontologyVersion`接続を削除し、元のオントロジー定義と検証済みのオブジェクトデータが含まれていないという制限を追加します。
</Callout>

一般グラフJSONは表示資料であり、サーバーのオントロジー・原文・分析記録全体を復元する形式ではありません。統合`.case.json`スナップショットは現在再インポートをサポートしていません。 [保存とインポート](/ja/docs/guide/import-export)を参照してください。
